# NIST SP 1108r4 보관 자료

출처: Gopstein et al. (2021), *NIST Framework and Roadmap for Smart Grid Interoperability Standards, Release 4.0*. [원문 PDF](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.1108r4.pdf), DOI: 10.6028/NIST.SP.1108r4.

## 포함 파일과 범위

- source.pdf: 전체 보고서의 PDF 28~38쪽(인쇄 12~22쪽), 총 11쪽 발췌본.
- converted/document.json: archive/plugins-docling-2026-11의 기존 JSON 바이트 그대로.
- converted/conversion-record.json: 기존 성공 상태·변환 시각·경과 시간·서버 버전·옵션·입력 hash를 보존하고 로컬 경로를 저장소 상대 경로로 바꾼 기록.
- SHA256SUMS: 이 파일 자체를 제외한 보관 파일의 SHA-256과 폴더 기준 상대 경로.

아카이브 JSON의 이미지 URI는 추출된 PNG 상대 경로다. 재생성 가능한 페이지·그림 PNG는 이 보관본에 포함하지 않는다. 문서 내용 측정에는 이 JSON을 사용하고 이미지가 필요한 소비자는 아카이브의 해당 파일을 사용한다. 변환 기록의 images는 당시 hash·추출 기록이며 이 폴더의 포함 파일 목록이 아니다. 변환 성공은 의미 정확도의 보증이 아니다.

[고정 변환 결과 재사용 지침](../../README.md#측정실험용-고정-변환-결과)을 따른다. 이 폴더와 LSR converted/는 지정 커뮤니티 공급 파일 목록에 없으므로 CLI·Desktop 배포에 포함되지 않는다.

## 라이선스와 출처 고지

미국 정부 NIST 직원 저작물로 미국 내 저작권 보호 대상이 아니다. NIST 자료를 저장소의 MIT로 재라이선스하지 않는다. 제3자 자료에는 별도 권리가 적용될 수 있다. 기존 아카이브의 출처·재인쇄 고지를 보존한다. [NIST 저작권·이용 정책](https://www.nist.gov/nist-research-library/nist-publications#copyright-use-and-licensing).
