# Changelog

## 0.0.1 — Draft / 미발행

이 PR이 병합될 때의 첫 커뮤니티 플러그인 버전입니다. 현재는 #1326을 기다리며 Ready·릴리스·병합하지 않습니다.

### 지원하는 기능

- docling-serve 주소·API 키 설정과 health/ready 수동 확인. 모델별 준비를 보증하지 않습니다.
- `.docling` → `.md`: 제목·문단·표 셀 텍스트 평탄화의 최소 변환. 공용 작업 화면과 CLI에서 시작·상태 확인·중단·결과 열기를 사용합니다.
- PDF → `.docling`의 **저장 전 준비 코드**: 고정 `litzio-pdf-en-v1`, 서버/OpenAPI 1.32.0·ready 확인, DoclingDocument 1.10.0·완전 success 검사, 단일 제출, 기본 1800초 전체 마감, 원본 해시 재확인, 출처·페이지 이미지 보존. **공용 K1 파일 작업의 최종 저장/시작 연결은 #1326 병합 뒤에 합니다.**
- ZIP 형식 버전 2에 원본/결과/OpenAPI/이미지 hash·크기, 프로필 전체, task ID·시각을 기록합니다. 이미지는 원본 바이트를 유지하고 큰 JSON 정수를 보존합니다.
- 변환 정책 3을 결과 `.md`의 표준 평문 문단에 플러그인 버전과 입력 `.docling` hash와 함께 기록합니다. [버전 구분과 SDK 대조](README.md)를 참고하세요.

### 제한과 아직 확인하지 못한 점

- 서버 작업 취소 API가 없습니다. 로컬 중단 뒤에도 제출된 서버 작업은 계속될 수 있습니다.
- 요청 한 번에 파일 하나입니다. 여러 파일은 각각 명시적으로 요청하며 큐·다중 선택·재시작 복원은 없습니다.
- Litzio 결과의 그림·캡션 번호·연결된 미주·중첩 목록·rich inline과 대조뷰는 지원하지 않습니다. 원본 `.docling`의 데이터는 보존합니다.
- SDK의 256 KiB·500블록·문자열·표 한도를 적용하며 조용히 잘라 저장하지 않습니다.
- 실제 공식 CUDA v1.32.0 이미지에는 고정 프로필이 요구하는 CodeFormulaV2가 없어 전체 프로필 변환이 failure였습니다. 값을 낮추지 않았고 모델을 설치하지 않았습니다. 전체 성공은 서버 모델 준비 뒤 재확인해야 합니다.
- helper 오류에는 task ID가 있지만 현재 공용 K1 실패 schema/고정 안내에는 이를 전달할 필드가 없습니다. SDK 보강 전까지 공용 오류의 task ID 표시를 보장하지 않습니다.
- 현재 `requiresSdk`는 기존 Host 계약을 유지합니다. #1326이 SDK 0.2.0과 권장 범위를 확정하면 master 병합 때 맞춥니다.
