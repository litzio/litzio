# Roadmap 후보

현재 구현은 [CHANGELOG](CHANGELOG.md)와 [변환 계약](README.md#문서-변환-규칙-004--1382)을 따릅니다. 아래는 순서이며 일정·구현 완료 약속이 아닙니다. 공개 SDK 경계를 내부 import나 직접 파일 쓰기로 우회하지 않습니다.

| 순서 | 목표 | 선행 작업과 경계 |
| --- | --- | --- |
| 0.0.4 | 원본 그림·번호와 출력 대응을 보존하는 변환기 | 공용 이미지 저장·번호 없음·최종 targets 사용. 불확실 번호는 원문+손실 요약으로 보존 |
| 0.0.5: 검수 1단계 #1364 | 불변 원본+수정→같은 변환 경로로 재생성 | 내부 review.json, 공식 전체 교체·CLI·Host 관리 연결·직접 편집 경고. PDF/JSON 원본 hash 보존 |
| 현재 0.0.7: 검수 2단계 #1408 | PDF 대조·양방향 대응·확인 페이지·마지막 위치 | 기존 공용 review·보관 PNG/bbox·비동기 순차 저장·공식 전체 파일 교체와 CLI |
| 검수 3단계 | 화면 안 항목 수정 | 기존 원본과 수정 목록을 재사용. 대응은 출력 revision마다 재계산 |
| 검수 4단계 | 검수 완료 승인 | 앞선 대조·수정·확인 기록을 사용 |

완료 승인(검수 4단계)과 화면 안 항목 수정은 이번 버전에서 구현하지 않습니다. 확인 기록은 2단계에 포함합니다. 전체 검수 흐름의 완료를 주장하지 않습니다.
