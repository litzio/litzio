# Roadmap 후보

현재 구현은 [CHANGELOG](CHANGELOG.md)와 [변환 계약](README.md#문서-변환-규칙-004--1382)을 따릅니다. 아래는 순서이며 일정·구현 완료 약속이 아닙니다. 공개 SDK 경계를 내부 import나 직접 파일 쓰기로 우회하지 않습니다.

| 순서 | 목표 | 선행 작업과 경계 |
| --- | --- | --- |
| 현재 0.0.4 | 원본 그림·번호와 출력 대응을 보존하는 변환기 | 공용 이미지 저장·번호 없음·최종 targets 사용. 불확실 번호는 원문+손실 요약으로 보존 |
| 이후: 검수 #1364 | 불변 원본+승인 수정→같은 변환 경로로 재생성 | 수정·확인한 페이지·승인은 .docling 안에 저장해 한 파일로 인계. PDF/JSON은 원본 hash로 보호하고 전체 봉투는 공식 경로로 다시 씀. .md·assets/는 밖의 결과물. 대응은 출력 revision마다 재계산 |

검수 기록 schema·승인/확인 UI·저장·재생 정책은 이번 버전에서 구현하지 않습니다. 0.0.3의 예약 opaque 슬롯을 검수 기능 완료로 간주하지 않습니다.
