# Roadmap 후보

현재 구현은 [CHANGELOG](CHANGELOG.md)와 [변환 계약](README.md#문서-변환-규칙-003--1368)을 따릅니다. 아래는 순서이며 일정·구현 완료 약속이 아닙니다. 공개 SDK 경계를 내부 import나 직접 파일 쓰기로 우회하지 않습니다.

| 순서 | 목표 | 선행 작업과 경계 |
| --- | --- | --- |
| 현재 0.0.3 | 원본 대응을 보존하는 변환기, 원본 PDF 봉투, 손실 보고 | 공개 SDK authorDocument만 사용. 그림은 빈 URL Figure이며 이미지 미포함 |
| 다음: 공용 작업 | 공식 이미지 저장과 authoring 한도 확대 | 특정 플러그인 전용 Core·Host 기능을 만들지 않음 |
| 그다음: 그림 | 원본 그림을 공식 asset으로 저장하고 Figure에 연결 | 공용 저장 작업 완료 후 진행 |
| 이후: 검수 #1364 | 불변 원본+승인 수정→같은 변환 경로로 재생성 | 수정·확인한 페이지·승인은 .docling 안에 저장해 한 파일로 인계. PDF/JSON은 원본 hash로 보호하고 전체 봉투는 공식 경로로 다시 씀. .md·assets/는 밖의 결과물. 대응은 출력 revision마다 재계산 |

검수 기록 schema·승인/확인 UI·저장·재생 정책은 이번 버전에서 구현하지 않습니다. 0.0.3의 예약 opaque 슬롯을 검수 기능 완료로 간주하지 않습니다.
