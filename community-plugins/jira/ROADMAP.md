# Roadmap

0.0.5는 공통 추가 조건 접기·PAT 계정 안내·입력 자동완성·열 선택·잘림과 전체 건수를 제공합니다. 회사 Jira 검색 성공은 소유자 확인이 필요합니다. 아래는 후보이며 제공 약속이나 구현 완료가 아닙니다.

- 자동 첫 조회·행 Tooltip·입력 옆 조회 버튼의 공통 계약 보강.
- 실제 회사 Jira 연결 결과에 따른 필요한 보완.
- 독립 배포와 유지 책임이 필요해지면 독립 저장소로 분리.

- **다음 버전 후보 — 보고서 문서에 이슈 표(시점 고정 기록) 넣기**: 공식 문서 write path와 공용 작업·CLI를 사용하고 출처·조회시각·범위를 남긴다. 자동 갱신이나 Jira 쓰기는 포함하지 않는다.
- 기본 7열·추가 후보 6열 선택과 500행 잘림·전체 건수, 입력 자동완성은 0.0.5에서 연결했습니다.

- Jira 저장 필터 불러오기.
- 공통 오류 상세 표시(SDK).
