# Changelog

## 0.0.2

- 현재 사용자 또는 선택 계정의 할당 이슈를 미해결(기본)·해결됨·전체로 수동 조회. 최근 수정순, 안전한 JQL 계정 escaping.
- 실제 반환 건수로 페이지 진행, 전체 8초 제한. 최대 500건까지 표시하며, 넘는 경우 따로 알리지 않음.
- 동일 `community.jira.issues` v2 작업으로 화면·CLI 조회. 기존 번호 조회를 같은 폼의 보조 입력으로 유지하고 번호 입력 시 우선 적용.
- 없는 이슈는 짧은 `없음 (404)` 상태. redirect는 기존 failed 고정 안내. healthCheck와 SDK 0.3.0 경계 유지.
- 제한: 자동 첫 조회·행 Tooltip·입력 옆 버튼·잘림 안내는 공통 계약의 후속 후보. 실제 Jira 확인은 소유자 수행.

## 0.0.1

- 설정 창에서 연결 확인. PAT 인증을 포함한 현재 사용자 조회와 안전한 고정 안내.

- Jira Data Center 9.12.28 대상 BASE_URL/API URL 설정, context path, 필수 PAT secret 및 Bearer 인증.
- 최대 20개 키의 상세 조회와 공통 표·입력 폼, 동일 CLI 공용 작업.
- 일부 404 행, 안전한 오류 분류, 8초 전체 제한과 redirect 거부.
- 이슈 키를 누르면 Jira 이슈 페이지로 이동. BASE_URL 기반 URL과 SDK 0.3.0 공통 링크 열을 사용.
- 제한: 번호 없는 검색·JQL·쓰기·동적 UI·맞춤 즐겨찾기 없음. 실제 회사 Jira는 소유자 확인 필요.
