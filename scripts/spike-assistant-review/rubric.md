# 저장본 채점 규칙

집계 단위는 정답 JSON의 본문 요소다. 변환기가 제외한 물리 1쪽과 반복 머리말·바닥글·쪽 번호는 요소 점수에서 뺀다. 첫 쪽 자료의 제외와 본문에 잘못 남은 요소는 별도로 센다. 기존 정답에서 diagnostic인 부록 M의 내부 표제는 별도 최상위 제목을 줄 수 없으므로 부록 아래 H2를 인정한다.

- NFKC와 공백만 정규화하고 대소문자·부호·숫자는 비교한다. 리치오 참조는 표시 글자로 읽는다. 명시된 두 페이지 문단은 한 문단에 합친 형태를 정답으로 삼고 각각 채점한다. 목록은 이름 18개를 항목별로 채점하고 열 우선 순서를 별도 기록한다.
- 표는 병합을 펴 값을 반복하며 첫 행의 그룹 제목과 둘째 행의 열 제목은 ` / `로 합쳐 머리글 한 행으로 둔다. 쪽이 넘어간 표는 표 두 개로 인정한다. 격자와 칸 텍스트, 인라인 수식 존재를 검사한다. 수식 칸의 수학적 동등성은 자동 채점에서 분리하고 사람이 판정한다. 중복된 병합 칸 두 개가 아니라 원본 수식 하나를 수학 판정 단위로 삼는다.
- 문자 표의 캡션은 해당 표, 그림 캡션은 해당 그림에 붙어야 한다. 번호는 리치오 표시와 본문 캡션의 조합을 인정한다. 원본 캡션 두 개가 한 그림으로 묶여서 둘째 캡션이 본문으로 남으면 각각 따로 판정한다.
- 표 전용 주석 자리가 없으므로 원래 기호와 문장이 독립 문단으로 해당 표 바로 아래에 이어져 있으면 맞음이다. 원본 호출이 있는 쪽 각주는 연결된 미주로 두며 UI가 재매긴 표시 번호는 감점하지 않는다. 정답에 호출이 없는 18·19는 가짜 호출을 만들지 않고 원문 번호가 든 독립 주석 문단을 인정한다. 원문 모양과 의미에 대한 관찰에서 이 한계를 표시한다.
- 세 독립 수식에는 수식 블록을 요구한다. 동일한 그림은 원본 위치 대응의 증거로 삼되 종류가 다른 것으로 판정한다. 수식 후보 위치는 앞뒤 본문 단서와 순서로 잡고 LaTeX는 사람이 읽는다. 실제 그림 둘은 원본 영역을 검토한 다음 기준 자산 해시로 보존을 확인한다. 교체 자산의 판독이 필요하면 별도로 기록한다.
- 문자열 전체 일치, 포함, 단어 겹침 순으로 대응 후보를 찾는다. 명확한 종류·문자·단계 위반은 틀림, 대응 후보가 없으면 없음이다. 하나의 출력 문단이 이름 목록처럼 여러 요소를 포함할 수 있다. 원본 요소로 대응되지 않는 출력 블록과 관계 변화는 별도 기록한다.
- 전후 차이는 동일 원본 ID별로 계산한다. 새로 맞음은 틀림·없음에서 맞음으로, 망가뜨림은 맞음에서 틀림·없음으로의 변화다. 구조 자동 점수와 수식의 수학적 동등성 판정을 함께 싣는다.
