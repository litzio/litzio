# 사용자 역할의 전체 발화

따옴표 안에 발화 또는 카드 응답을 그대로 적었다. 위치를 가리킨 부분은 각 턴 끝에 표시했다. 마지막 ‘좋아’는 화면 검사 뒤 실험 기록에만 남겼다.

## A-1-1

1. “주간 보고 모으는 거 만들어 줘.”
2. “열린 폴더의 사람별 주간 보고 문서요.” / “사람별로 이번 주 한 일과 다음 주 할 일만 모아서 새 문서 하나로 만들어 줘.” / “매주 버튼을 눌러 반복”
3. “표 아래에 빠진 사람도 보여 줘. 모래 팀은 가람, 다솔, 마루, 보늬, 여울이야. ‘새 문서 저장’을 눌러도 오늘 문서가 있으면 새 문서가 안 생겨. ‘취합 문서 만들기’로 새 문서를 만들어 바로 열어 줘.” 가리킨 부분 **표 아래** · **‘새 문서 저장’**.
4. “좋아”

## A-1-2

1. “주간 보고 모으는 거 만들어 줘.”
2. “열린 폴더의 사람별 주간 보고 문서요.” / “사람별로 이번 주 한 일과 다음 주 할 일만 모아서 새 문서 하나로 만들어 줘.” / “매주 버튼 눌러서 쓰고 싶어.”
3. “사람별 보고 목록 아래에 빠진 사람도 보여 줘. 모래 팀은 가람, 다솔, 마루, 보늬, 여울이야. ‘새 문서로 저장’ 단추 이름은 ‘취합 문서 만들기’로 해 줘.” 가리킨 부분 **사람별 보고 목록 아래** · **‘새 문서로 저장’ 단추**.
4. “좋아”

## B-1-1

1. “주간 보고 모으는 거 만들어 줘.”
2. “표의 ‘팀’ 열에는 사람별 보고를 보여 줘. 표 아래엔 빠진 사람도 보여 줘. 모래 팀은 가람, 다솔, 마루, 보늬, 여울이야.” / “열린 폴더의 사람별 주간 보고 문서에서 모아 줘.” / “사람 이름 가나다순으로 이번 주 한 일과 다음 주 할 일만 모아서 ‘취합 문서 만들기’로 새 문서를 만들어 열어 줘.” 가리킨 부분 **표의 ‘팀’ 열** · **표 아래**.
3. “‘이번 주 한 일’이랑 ‘다음 주 할 일’이 들어 있어. 이름이랑 주차는 잘 모르겠어, 알아서 해 줘.” / “잘 모르겠어, 알아서 해 줘.”
4. “사람마다 문서 선택을 눌러야 해서 번거로워. 폴더를 한 번만 고르면 제출한 사람 보고를 한꺼번에 찾아 줘.” 가리킨 부분 **사람마다 문서 선택**.
5. “좋아”

## B-1-2

4. “열어 둔 자료 폴더에 있어. 다른 건 잘 모르겠어, 알아서 해 줘.”
5. “좋아”

## A-2-1

1. “CSV 올리면 그래프 그려 주는 거.”
2. “그래프 날짜는 왼쪽부터 오래된 순서로 보여 줘. 그래프 위에서 기준선을 입력하고 넘은 날을 그래프에 표시해 줘.” 가리킨 부분 **그래프 날짜는 왼쪽부터** · **그래프 위에서**.
3. “그래프 아래 초과 날짜와 값 목록을 새 리치오 문서로 저장하고 바로 열 수 있게 해 줘.” 가리킨 부분 **그래프 아래 초과 날짜와 값 목록**.
4. “그래프에서 기준을 넘은 점 자체를 다른 색으로 보여 줘. 새 문서 표 위에 붙은 설명은 빼고 초과 날짜와 값만 남겨 줘.” 가리킨 부분 **그래프에서 기준을 넘은 점 자체** · **새 문서 표 위에**.
5. “좋아”

4. “좋아”

CSV를 바꾸면 이전 자료의 그래프와 초과 목록이 새 자료에 맞게 갱신된다.”
2. “좋아”
