## 상황

이 문서는 반복 작업을 위한 시작점입니다. 확인한 **사실**과 남은 일을 구분해 적습니다.

*   작업 목적과 적용 범위를 적습니다.
*   변경 내용과 근거를 함께 남깁니다.

## 결정 근거

:::{table}

| 확인 항목 | 결과        |
| ----- | --------- |
| 문서 구조 | 제목·절·목록·표 |
| 검증 근거 | 재현 절차와 관찰 |
:::

완료 비율은 $r = n / N$으로 정리합니다.

```{math}
:label: completion

r = \frac{n}{N} \times 100
```
