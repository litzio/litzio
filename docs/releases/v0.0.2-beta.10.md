## 포함 변경 / 한국어 Release 본문

Litzio Windows x64 unsigned Beta입니다. beta.9 이후 변경을 정리했습니다.

- **보안 런타임 갱신:** Node.js Brotli 디코더의 high 등급 CVE-2026-111497에 대응합니다. Desktop은 Electron 45.3.0(번들 Node 24.22.2)을 사용하고 CI·개발 기준은 Node 24.22.2입니다. 별도 시스템 Node와 이미 실행 중인 daemon은 사용자가 갱신·재시작해야 합니다(PR #1515).
- **비서 문서 작업:** 기존 문서 변경은 사본에 쌓고 비교 탭에서 확인한 뒤 **적용**합니다. 셸 없이 Host 도구로 사본을 읽고 편집하며, 표·목록·그림·캡션의 구조화 생성·편집을 지원합니다. 원본 변경 감지와 적용 시 보호를 유지합니다(PR #1497·#1504·#1516, #1500).
- **비서 자율성:** 발화한 창의 화면 정보를 조회하고 탭·폴더를 조작합니다. 실패를 분류하고 복구 경로를 제공하며 기본 권한은 전체 접근, 정책 거부 시 열린 폴더 범위로 자동 하향합니다. 읽기 전용 턴에도 플러그인 조회가 가능하고 Copilot에도 같은 리치오 도구를 MCP로 제공합니다(PR #1501·#1514·#1517·#1508·#1503·#1509).
- **Docling 검수:** 플러그인 비서 스킬 **Docling · 검수**를 제공합니다. 경로로 검수 대상을 찾고 큰 대화 이력으로 이어 보내기가 실패하던 문제를 수정했습니다. 이미지 승인 질문 카드를 한국어로 표시합니다. 원본 대조 다시 열기, 페이지 확인 기록, 검수 묶음·완료 근거, 원본 렌즈·그림/표 목록, 원문 증거 후보와 국소 교정 제안을 제공합니다. 교정 대상은 리치오 문서이며 이미지 조회에는 사람의 범위 승인이 필요합니다(PR #1415·#1468·#1470·#1472·#1474·#1480·#1482·#1483·#1484·#1488·#1495·#1496·#1498).
- **플러그인 사용:** 기본 화면·조회 결과·파일 작업, 연결 설정·확인과 제작 템플릿을 개선했습니다. 사용자 추가 플러그인 제거, daemon 재시작 후 작업 이력 보존, 플러그인 추가 창 초안 유지를 지원합니다(PR #1398·#1399·#1400·#1406·#1418·#1432·#1442·#1464). SDK의 새 기능별 최소 버전은 [플러그인 계약](../design/plugin-stage1-v1.md)을 따릅니다.
- **Desktop과 화면:** 창 닫기는 트레이에 유지하고 명시적 종료 경로를 제공합니다. 좁은 창의 탐색기·비교 화면 블록 라벨과 번역, 비서 진행 표시 위치·읽던 위치 보존·비동기 질문, Codex 계정 사용 한도 표시를 개선했습니다. 로컬 Host의 일시적 시작 오류 후 상태 표시가 회복됩니다. Host 등록 전 연결 확인, 원격 Host 템플릿 갤러리, 하위 폴더 휴지통 이동도 제공합니다(PR #1449·#1456·#1505·#1506·#1444·#1452·#1447·#1454·#1489·#1471·#1473·#1433).

### 알려진 제한과 업데이트 안내

- unsigned Beta로 Windows SmartScreen 경고가 나타날 수 있습니다. Stable 공개는 보류합니다.
- Beta 채널에서 공개된 beta.10을 업데이트 대상으로 확인하거나 [Release](https://github.com/litzio/litzio/releases/tag/v0.0.2-beta.10)에서 설치 파일을 내려받으세요. 실제 GitHub beta.9 → beta.10 설치·업데이트는 미검증입니다.
- 별도 시스템 Node는 24.22.1 이상으로 갱신하고 실행 중인 daemon을 재시작하세요. Desktop 번들 Node와 별도로 적용해야 합니다.
- Copilot에서는 질문 카드를 대신해 텍스트로 질문합니다. 원본이 바뀐 뒤 사본을 다시 기준화하는 기능은 후속 작업입니다.
- Docling은 지정 커뮤니티 플러그인이며 공식 플러그인이 아닙니다. 고정 변환 결과·합성 fixture의 통과가 임의 문서의 검수 품질을 보증하지 않습니다.
- IeumDoc beta.4에서 Litzio로 자동 업데이트되지 않습니다. 새 설치가 필요하며 과거 데이터·설정·복구 기록을 이전하지 않습니다.

## 확인 범위와 남은 검증

- 준비 작업은 버전·fixture·문서만 변경했습니다. window-startup 대상 검사·문서 검사 결과는 준비 PR의 근거를 따릅니다.
- 보안 PR #1515의 Electron/Node 실행·packaged 대상 검사와 로컬 feed 다운로드 probe 결과는 해당 PR의 근거입니다. 이번 준비 작업에서 재실행한 결과나 실제 공개 feed 업데이트 성공으로 간주하지 않습니다.
- Windows packaged·설치·로컬 feed 업데이트는 merge queue CI, 전체 배포 검증은 release workflow가 담당합니다. 로컬 package·test:packaged·test:update·test:uninstall은 실행하지 않습니다.
- beta.10 태그·workflow·공개 자산은 아래 오케스트레이터 확인 결과를 기록합니다. 실제 GitHub beta.9 → beta.10 설치·업데이트는 **미실행·미검증**이며 설치 상태를 보존했습니다.
- 이 후속 기록 작업은 문서만 변경하며 자산 다운로드·설치나 Release 수정을 실행하지 않았습니다. CI·로컬 feed 성공을 실제 GitHub 설치·업데이트 성공으로 간주하지 않습니다.
