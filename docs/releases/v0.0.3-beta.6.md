## 사용자 수동 확인 안내

Tiptap·ProseMirror 갱신(#1840)은 CDP 조합 입력으로만 시험했다. 실제 Windows Microsoft 한국어 IME의 이벤트 순서는 재현하지 못하므로 아래 다섯 가지는 실제 IME로 확인해야 하며, 제품 성공으로 선언하지 않는다.

1. 문단 끝에서 한글을 조합하던 중 Enter: 조합 중인 글자가 남고 새 문단이 정확히 한 번 생기는지(Enter가 두 번 처리되거나 글자가 사라지지 않는지)
2. 조합 중 Backspace: 자모 단위로 지워지고, 이전 글자나 앞 블록이 지워지거나 합쳐지지 않는지
3. 표 셀·표 캡션·Figure 캡션·각주 정의 안에서 1, 2와 같은 동작
4. 빠르게 연속 입력한 직후 Enter/Backspace(예: `안녕하세요` 입력 직후 Enter)
5. 명령 센터나 대화 상자를 닫고 Editor로 돌아온 직후 바로 한글을 조합해 입력: caret이 원래 위치에 있는지(#542 경로)

## 게시된 한국어 Release 본문

서명 없는 Windows Beta 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows Beta. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.3-beta.6 Beta의 beta.5 이후 주요 변경입니다.

- **작업 막대와 알림 위치.** 창 왼쪽에 항상 보이는 작업 막대에서 탐색기, 템플릿 갤러리, 플러그인 화면, 설정과 연결 상태를 바로 엽니다. 저절로 펼쳐지는 알림은 종이 있는 오른쪽 위, 탭 줄 아래에 나타납니다.
- **비서.** Codex와 Copilot 대화 기록을 한곳에서 검색해 이어 가고, 대화의 이름을 바꾸거나 보관할 수 있습니다. 입력창에서 파일을 바로 첨부하고 보낸 메시지를 복사하거나 다시 쓸 수 있습니다. 공급자 프로세스 종료 확인이 실패해도 다시 시작하지 않고 다음 연결에서 복구합니다.
- **편집.** 표에서 위·아래 화살표가 같은 열로 이동합니다. 목록 아래 문단의 Backspace, 제목 맨 앞의 Enter가 일반 편집기처럼 동작합니다. 선택한 글자 뒤에 미주를 넣는 버튼이 생겼고, 제목 번호를 켜면 같은 수준의 제목 글자가 한 줄로 맞춰집니다.
- **붙여넣기.** 메모장이나 AI 채팅의 마크다운 글자를 붙이면 서식으로 들어갑니다(글자 그대로는 Ctrl+Shift+V). 레이블 있는 표·그림·수식을 같은 문서에 붙이거나 복사해 끌어 놓으면 저장 실패 대신 그 자리에서 알려 줍니다.
- **저장.** `**정확도(Accuracy)**를`처럼 문장부호로 끝나는 굵게·기울임 뒤에 한글이 붙은 글과, 줄 맨 앞이 `+++`·`%`·`:::`인 문단을 저장할 수 있습니다. `litzio check`는 강조가 되지 못한 구분자를 경고합니다.
- **보안과 기반.** Electron 45.4.1(Node 24.22.3), electron-builder·electron-updater, Tiptap·ProseMirror와 보안 수정이 있는 의존성을 갱신했습니다. 큰 문서에서 입력·열기 때의 반복 측정을 줄였습니다.

**알려진 제약.** Tiptap·ProseMirror 갱신 뒤 실제 Windows 한국어 IME(조합 중 Enter·Backspace, 표 셀·캡션·각주 안 입력, 대화 상자를 닫은 직후 입력)는 확인하지 않았습니다. 마크다운 붙여넣기는 글 전체를 읽을 수 있을 때만 서식으로 넣고, 하나라도 읽을 수 없으면 일반 글자로 넣습니다. 문장부호 경계의 굵게·기울임은 바깥 글자 하나를 문자 참조(`&#xB97C;` 등)로 저장합니다.

개발 단계로 과거 데이터 하위 호환을 보장하지 않습니다. 비서의 변경 보기·되돌리기는 공급자 편집 이벤트가 있는 기존 UTF-8 파일(1 MiB 이하)에 한정되며 셸 직접 쓰기 등은 경로만 표시합니다. [현재 비서 한계](https://github.com/litzio/litzio/blob/v0.0.3-beta.6/docs/design/main-agent-v1.md#현재-한계)를 확인하세요.

Beta 설치본의 최초 기본 채널은 Beta이며 저장된 선택은 유지합니다. Beta 채널의 대상은 0.0.3-beta.6이며 Stable 채널에는 Beta를 제공하지 않습니다. 이번 Beta는 beta.yml만 제공합니다. 업데이트 전에 문서를 저장하세요. 실제 GitHub 설치·업데이트, SmartScreen·게시자 표시와 서명 배포는 미검증입니다.

전체 변경과 검증 범위는 [배포 기록](https://github.com/litzio/litzio/blob/v0.0.3-beta.6/docs/releases/v0.0.3-beta.6.md)에 있습니다.
