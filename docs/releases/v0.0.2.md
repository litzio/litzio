## 포함 변경 / 한국어 Release 본문

서명 없는 Windows Stable 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows release. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.2 Stable의 beta.10 이후 주요 변경입니다.

- **비서 채팅:** 답변 표시를 부드럽게 하고 작업 단계를 대화 흐름에서 보여 줍니다. 미답변 질문을 보관하고 나중에 답할 수 있으며 권한 요청도 카드로 확인합니다. Copilot 대화 재연결과 문서 수정 도구 안내를 고쳤습니다. 새 대화에 이전 대화가 다시 나타나는 문제를 고치고, 메시지 다시 시도를 단순화했으며 실행 중에도 새 대화로 이동할 수 있습니다(PR #1526·#1545·#1534·#1537·#1524·#1549·#1551·#1557·#1558).
- **문서 수정:** 입력창 위에서 대기 중인 변경을 확인하고 비교 탭을 바로 엽니다. 적용한 내용은 편집기에 즉시 반영되고 적용·버리기 후 비교 탭은 닫힙니다. 비서가 이미지를 가져와 문서에 넣을 수 있습니다(PR #1543·#1553·#1556).
- **Docling 검수:** 문제 목록을 중심으로 원문과 문서를 대조하는 검수 화면 A 배치를 제공합니다. 비서 교정을 즉시 적용하고 되돌릴 수 있으며 검수 화면에서 문서를 직접 편집·저장합니다. 이미지 확인 전 별도 승인 대기를 없앴습니다(PR #1525·#1535·#1544·#1532).
- **비서 안내:** 작업 지시문을 한국어로 정리하고 현재 문서 작업 방식에 맞췄습니다(PR #1550).
- **보안과 배포:** 보안 런타임 갱신 전 beta.9 이하 설치 자산을 내렸습니다. 인증서 없는 Stable 배포를 허용하며 서명 없음과 Windows 경고 가능성을 안내합니다(PR #1559).

Stable 설치본의 최초 기본 채널은 Stable입니다. 저장된 채널 선택은 유지되며 Beta 채널에서도 더 높은 Stable 버전을 받을 수 있습니다. 이번 Stable은 latest.yml을 제공합니다. 실제 GitHub 설치·업데이트는 아직 미검증입니다. IeumDoc beta.4에서는 자동 업데이트되지 않아 새 설치가 필요합니다. Docling은 커뮤니티 플러그인입니다.

## 확인 범위와 남은 검증

- 버전·startup fixture·beta.10 → Stable opt-in GitHub harness와 문서만 변경한다. 대상 검사 결과는 준비 PR에 기록한다.
- Windows packaged·설치·로컬 feed 업데이트는 merge queue CI, 전체 배포 검증은 release workflow가 담당한다. 로컬 패키징·설치·업데이트·제거 검사는 실행하지 않는다.
- 실제 GitHub beta.10 → Stable 설치·업데이트는 미실행·미검증이다. CI local-feed 결과와 구분한다.
