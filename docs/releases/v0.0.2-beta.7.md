## 준비 단계 (당시 범위)

- Desktop 후보와 startup fixture를 `0.0.2-beta.7`로 올린다. opt-in 실제 GitHub harness는 `0.0.2-beta.6 → 0.0.2-beta.7`이며 beta.7 공개 후 실행할 수 있다. 실제 공개 beta.6 출발 CI의 고정 installer·해시는 유지한다.
- 소유자 결정(2026-11-04, #1171): 플러그인·Docling 없는 제품을 Beta로 릴리스한다. verify 통과 시 추가 승인 없이 unsigned-beta 공개하는 결정이며, 이 준비 PR은 태그 생성·workflow 실행·공개·병합을 수행하지 않는다.
- 로컬 패키징·verify-release·test:packaged·test:update·test:uninstall은 실행하지 않는다. 설치물 검증은 CI와 release workflow가 담당한다.

## 사용자 영향과 알려진 제한

- **업데이트 전에 열려 있는 문서를 저장하세요.** 개발 단계이며 과거 데이터의 하위 호환과 자동 migration을 제공하지 않는다. beta.6의 미저장 복구 초안·일부 화면 설정은 이어지지 않는다. 중요한 문서는 별도로 백업한다.
- **Docling과 플러그인은 사용할 수 없다.** 보관 브랜치는 과거 소스이며 현재 지원 기능이 아니다. 소유자가 명시적으로 재개할 때 컨셉을 다시 개발한다.
- 구 daemon과 프로토콜이 다르면 연결을 거부한다. 해당 daemon과 일치하는 CLI로 종료한 뒤 원하는 버전으로 시작한다. 제품 버전 차이는 경고한다.
- Windows x64 unsigned Beta이며 Stable은 아직 없다. 실제 GitHub beta.6 → beta.7 설치·업데이트는 이 PC 설치 상태 보존 제약으로 **미실행·미검증**이며 소유자 수동 확인 대상이다.
