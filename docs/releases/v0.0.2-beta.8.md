## 준비 범위와 승인

- 소유자가 2026-11-05 이번 Beta 배포를 승인했다. 준비 PR은 버전·startup fixture·공개 beta.7 → beta.8 opt-in harness와 문서를 갱신한다.
- 태그 생성과 릴리스 workflow 실행은 오케스트레이터가 담당한다. 준비 에이전트는 병합하지 않는다.
- 로컬 패키징·test:packaged·test:update·test:uninstall은 실행하지 않는다. 필수 CI(Windows Desktop 포함)와 release workflow가 설치물 검증을 담당한다.
- 실제 공개 beta.6의 lifecycle helper 없는 설치본에서 출발하는 별도 CI 회귀는 고정 자산·해시를 유지한다.

## 포함 변경 / 한국어 Release 본문 준비 초안

Litzio Windows x64 unsigned Beta입니다. 집계 범위는 `git log v0.0.2-beta.7..origin/master`의 master `8e9c1d37b65441cf4f2edab835141c698dac4b85`까지입니다.

- **여러 Host 연결:** Desktop에서 원격 Host를 등록·연결하고 로컬·원격 탐색기와 문서·비서 대화를 한 화면에서 이용할 수 있습니다([#1174](https://github.com/litzio/litzio/issues/1174), PR #1176~#1180). 원격 Host에 새 문서·폴더를 만들 수 있습니다([#1190](https://github.com/litzio/litzio/issues/1190), PR #1192). Host 제거 시 작업 요약 오류를 수정하고([#1196](https://github.com/litzio/litzio/issues/1196), PR #1197), 활성 Host의 실행 계정을 화면과 daemon 상태에 표시합니다([#1199](https://github.com/litzio/litzio/issues/1199), PR #1200).
- **Visual 비교와 복구:** Editor 화면 그대로 저장 전 변경을 비교하고, 복구 화면에서도 Visual 비교를 사용할 수 있습니다([#1201](https://github.com/litzio/litzio/issues/1201), PR #1203·#1209·#1214).
- **플러그인 1단계:** 최소 SDK, 로컬 artifact 등록·신뢰·활성화와 OneDrive 공식 플러그인을 제공합니다(PR #1204). 과거 플러그인의 일괄 복구가 아닌 ADR-0019·0020에 따른 새 1단계입니다. 범위는 [플러그인 계약](../design/plugin-stage1-v1.md)을 따릅니다.
- **동적 UI 1단계:** 기본 UI를 유지하면서 비서가 생성한 뷰를 새 탭에서 열고 즐겨찾기로 다시 이용할 수 있습니다([#1210](https://github.com/litzio/litzio/issues/1210), PR #1212·#1213·#1215).
- **비서와 내부 안정화:** 비서 제공자 상태 표시를 통일했습니다([#1207](https://github.com/litzio/litzio/issues/1207), PR #1208). daemon RPC 연결 격리·시작 handshake를 개선하고 CI 분리와 내부 리팩터링을 진행했습니다.

## 알려진 제한

- **업데이트 전에 열려 있는 문서를 저장하세요.** 개발 단계이며 과거 데이터의 하위 호환·자동 migration을 제공하지 않습니다. 중요한 문서는 별도로 백업하세요.
- Host 인증은 아직 없습니다([#1145](https://github.com/litzio/litzio/issues/1145)). 웹 브라우저에서는 원격 Host를 등록할 수 없습니다.
- Copilot 동적 UI는 fixture 검증만 수행했으며 실제 제공자 응답 검증은 완료하지 않았습니다. Copilot의 `[object Object]` 표시 문제는 남아 있습니다([#1181](https://github.com/litzio/litzio/issues/1181)).
- OneDrive는 로그인·동기화 상태를 판정하지 않습니다.
- 원격 템플릿 갤러리는 지원하지 않습니다([#1185](https://github.com/litzio/litzio/issues/1185)). 원격 탭 순서 복원은 후속 과제입니다([#1184](https://github.com/litzio/litzio/issues/1184)).
- Windows x64 unsigned Beta이며 Stable은 아직 없습니다. 실제 GitHub beta.7 → beta.8 설치·업데이트는 **미실행·미검증**이며 CI 결과로 대신하지 않습니다.

## 업데이트 방법

- Litzio의 업데이트 채널을 Beta로 선택하고 업데이트를 확인하세요. beta.8 공개 후 beta.7에서 업데이트할 수 있습니다. 또는 [Releases](https://github.com/litzio/litzio/releases)에서 Windows 설치 파일을 내려받으세요.
- IeumDoc beta.4에서 Litzio로 자동 업데이트되지 않습니다. 새 설치가 필요하며 이전 앱의 데이터·설정·복구 기록은 이전되지 않습니다.
- daemon 프로토콜이 다르면 연결을 거부합니다. 해당 daemon과 일치하는 CLI로 종료한 뒤 원하는 버전으로 시작하세요. 제품 버전 차이는 경고합니다.
