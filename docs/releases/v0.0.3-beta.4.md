## 한국어 Release 본문

자동 생성된 "What's Changed" 목록을 아래 본문으로 바꿨고 API로 다시 읽어 확인했다. 초안과 달라진 것은 마지막 줄의 배포 기록 링크를 tag가 아닌 master로 둔 것뿐이다(공개 결과가 이 기록에 반영되므로).

서명 없는 Windows Beta 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows Beta. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.3-beta.4 Beta의 beta.3 이후 주요 변경입니다.

- **객체 편집:** 그림·표·수식의 속성 배치를 맞추고, 속성·원문 편집·이미지 교체를 도구 줄에서 구분했습니다. 좁은 화면의 번호 선택지 잘림도 고쳤습니다.
- **문서 설정과 검토 상태:** 문서에 초안·검토 중·검토 완료 상태를 붙일 수 있습니다. 설정을 정렬된 속성 표로 정리하고 제목·캡션 번호와 참조 표기를 선택하기 쉽게 바꿨습니다. 검토 상태는 편집을 막지 않습니다.
- **새 문서 저장:** 저장할 폴더가 없으면 만들고 그림 파일에 알아보기 쉬운 이름을 붙입니다.
- **플러그인 제작자용:** 문서 보기의 호버 테두리·배율과 그림 축소를 고쳤습니다. 스크롤·블록 클릭·보이는 블록 위치 알림, 우클릭 메뉴와 이름을 숨긴 선택 상자를 제공합니다. 저장된 문서를 읽고 공식 저장 경로로 쓰는 기능도 추가했습니다.
- **PDF 보기:** PDF 처리 라이브러리를 보안 수정판으로 올렸습니다.

알려진 제약: 객체 도구 줄이 긴 수식의 시작 부분을 hover 중 가릴 수 있습니다. 문서 보기에서 표 테두리의 최소 픽셀 처리 때문에 축소가 정확한 비율과 조금 다를 수 있습니다. 대화상자·메뉴를 닫은 직후 입력의 즉시 복귀는 보장하지 않으며 명령 센터 검사는 Escape 뒤 100ms 기준입니다. Windows 백그라운드 서비스 시작 지연과 제거 뒤 실행 파일 잔존의 간헐 실패는 원인 미확정입니다.

개발 단계로 과거 데이터 하위 호환을 보장하지 않습니다. 비서의 변경 보기·되돌리기는 공급자 편집 이벤트가 있는 기존 UTF-8 파일(1 MiB 이하)에 한정되며 셸 직접 쓰기 등은 경로만 표시합니다. [현재 비서 한계](https://github.com/litzio/litzio/blob/v0.0.3-beta.4/docs/design/main-agent-v1.md#현재-한계)를 확인하세요.

Beta 설치본의 최초 기본 채널은 Beta이며 저장된 선택은 유지합니다. Beta 채널의 대상은 0.0.3-beta.4이며 Stable 채널에는 Beta를 제공하지 않습니다. 이번 Beta는 beta.yml만 제공합니다. 업데이트 전에 문서를 저장하세요. 실제 GitHub 설치·업데이트, SmartScreen·게시자 표시와 서명 배포는 미검증입니다.

전체 변경과 검증 범위는 [배포 기록](https://github.com/litzio/litzio/blob/master/docs/releases/v0.0.3-beta.4.md)에 있습니다.

## 검증과 게시 판단

아래는 준비 PR #1731 당시의 검증 기록이다. 현재 게시 결과는 위 공개 결과를 따른다.

후보 `43d40f50375a67c4085add7d1a6de838b0a8fbfa`에서 감시 대상 밖 checkout의 Host 데이터·비서 작업·비서 설정·daemon·플러그인 설정·ResetGuard 여섯 경로와 profile 위치·cache·TEMP/TMP를 분리하고 frozen install → 공식 package → `verify-release.ts --tag v0.0.3-beta.4`가 통과했다. installer·beta.yml·PE 버전·blockmap을 검증했으며 설치 파일은 실행하지 않았다. Electron은 실행하지 않아 profile 사용 자체는 검증하지 않았다. Desktop 단위 검사 105/105, Desktop typecheck, docs:check와 git diff --check가 통과했다. 이후 변경은 문서 검증 기록뿐이다. 직접 시작한 검증 프로세스는 종료됐고 checkout과 산출물은 보존했다. PR CI 결과는 PR 본문에 기록한다. 실제 AI 호출·전체 packaged·브라우저·실제 Electron UI·설치·업데이트·제거·SmartScreen은 로컬 미실행·미검증이다. 이전 native 너비 1440 기대/1439 관찰 제한은 재검증하지 않았다.
