## 게시된 한국어 Release 본문

서명 없는 Windows Beta 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows Beta. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.4-beta.3의 0.0.4-beta.2 이후 주요 변경입니다.

- **복잡한 표 편집.** 병합된 칸, 여러 머리글 행, 칸 안의 문단과 목록을 표시합니다. 문서 탭과 플러그인 문서 보기에서 칸의 글자, 서식, 줄바꿈을 고친 뒤 저장하고 다시 열 수 있습니다. 표의 격자와 칸 안의 문단·목록 구조는 유지됩니다.
- **강조 세트.** 자주 찾는 단어를 색으로 표시하고 세트에 이름을 붙입니다. 문서마다 세트를 선택하거나 폴더 기본으로 지정할 수 있습니다. 문서에서 글자를 선택해 단어를 더하고, 이미 강조된 단어의 메뉴에서 색을 바꿀 수 있습니다.
- **수식 미리보기와 대용량 문서.** 인라인 수식을 적용하기 전에 입력창에서 확인할 수 있습니다. 큰 문서의 첫 편집과 이후 입력 때 화면이 하는 일을 줄였고, 그림을 포함한 큰 문서 작성 중에도 다른 창의 요청을 더 빨리 처리합니다.
- **작업 화면과 비서.** 알림은 작업 막대의 설정 바로 위에 있습니다. 플러그인과 템플릿 갤러리의 머리가 한 줄로 줄었고, 비서 입력창은 내용에 맞춰 커집니다.
- **플러그인.** 불러오는 중과 응답이 늦을 때 상태가 표시됩니다. 파일 우클릭과 문서 탭의 ⋯ 메뉴에 플러그인 동작을 추가할 수 있습니다. 별도 문서 가져오기 플러그인의 PDF 변환 메뉴, Word 파일 한 번 클릭, 한 줄 머리의 파일 정보를 쓰려면 이 Beta 이상의 Host가 필요합니다.

**채널.** Stable에서 이 Beta를 받으려면 설정에서 Beta 채널을 선택하세요. 이미 저장한 채널 선택은 유지됩니다. 실제 GitHub 설치·업데이트는 미실행·미검증입니다.
