## 준비 단계

- Desktop 후보를 `0.0.2-beta.6`으로 올리고 startup fixture를 맞춘다. 기본 포함 Docling·AI agent manifest는 앱 semver를 사용하고 내용 식별은 revision을 유지한다(#1090 / PR [#1092](https://github.com/litzio/litzio/pull/1092)). 기존 테스트는 package.json의 version과 비교하므로 별도 고정 기대값을 추가하지 않는다.
- opt-in 실제 GitHub harness는 이미 같은 브랜드 Litzio `0.0.2-beta.5 → 0.0.2-beta.6`이다. 두 버전이 공개된 뒤에만 실행할 수 있다. CI local-feed fixture Stable `0.0.1 → 0.0.2`, Beta `0.1.0-beta.1 → 0.1.0-beta.2`는 유지한다.
- #1081(제3자 라이선스 고지), #1093(Copilot 설정 확장)은 포함 예정이지만 아직 병합 전이다. 오케스트레이터의 병합 통보 후 origin/master를 merge하고 아래 표를 확정한다.
- 제외: tag 생성, release workflow 실행·게시, 준비 PR 병합, 로컬 앱 실행·설치·패키징, test:update·test:uninstall, 브라우저(Edge 포함), PATH·레지스트리·사용자 데이터 변경. 임시 폴더를 재귀 삭제하지 않는다.

| 검사 | 결과 |

| tag·release workflow·게시·공개 자산 확인 | 미실행. 준비 PR 병합 뒤 별도 단계 |

후속: 두 대기 PR 반영 → 준비 PR 검증/승인/master 반영 → 실제 환경 규칙 확인 → 검증된 master commit에 tag·`unsigned-beta` workflow → 세 자산(설치 파일·blockmap·beta.yml)의 크기·SHA-256·SHA-512 대조 → 한국어 Release 본문과 이 기록을 실제 결과로 갱신한다. 이 준비 문서는 게시나 수동 검증 완료의 근거가 아니다.

## 한국어 Release 본문 초안 (미게시)

> # Litzio v0.0.2-beta.6
>
> Windows x64용 unsigned Beta 후보입니다. 아직 공개 전이며 게시 시 자산과 검증 결과를 확정합니다.
>
> **주요 변경**
>
> - 설정을 문서 옆 작업 탭으로 열고 라이트·다크를 빠르게 전환합니다. 플러그인 목록에서 활성화·설정·버전 정보를 관리합니다.
> - 비서에 GitHub Copilot CLI를 추가하고 Codex 스킬 `/`·파일 참조 `@`·구조화된 질문 답변을 제공합니다. 대화 복원·Markdown 답변·복사·입력 후보 선택을 개선했습니다.
> - 외부 변경과 저장 충돌을 비교하거나 다시 불러옵니다. 숨은 탭 목록, 탐색기 우클릭·패널 너비 조절, 편집 중 블록 막대와 묶음 알림을 제공합니다.
> - Docling 수동 페이지 검수를 별도 탭으로 분리하고 이미지 클릭 선택·제외 표시·대시보드를 개선했습니다. 자료를 검토하지 못한 AI 결과를 정상 완료와 구분합니다.
> - 일반 HTTP의 복사 대체 경로, Mermaid 라벨 배경과 이름 변경 후 focus를 수정했습니다.
> - **샘플은 매 시작마다 원본으로 교체됩니다. 샘플 안에서 작업한 파일은 다른 폴더에 복사해 보관하세요.**
>
> **설치와 주의 사항**
>
> 게시 후 Assets의 `Litzio-Setup-0.0.2-beta.6.exe`를 사용합니다. Node.js나 pnpm은 별도로 필요하지 않습니다. 비서는 선택한 Codex 또는 Copilot CLI 설치·로그인, Docling 변환은 별도 REST 서버와 AI 검수용 Codex가 필요합니다.
>
> 코드 서명되지 않은 Beta이므로 Windows SmartScreen·조직 보안 정책 경고가 나타날 수 있습니다. 체크섬은 무결성 확인용이며 게시자 인증을 대신하지 않습니다. Stable은 아직 공개하지 않습니다.
>
> 개발 단계이므로 과거 문서·복구 기록·설정의 하위 호환성을 보장하지 않으며 자동 migration도 제공하지 않습니다. 중요한 문서는 별도 백업해 주세요. IeumDoc beta.4는 Litzio로 자동 업데이트되지 않으며 새 설치가 필요하고 데이터·설정·복구 기록은 이전되지 않습니다.
>
