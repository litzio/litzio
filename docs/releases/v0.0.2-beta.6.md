## 준비 단계 (당시 범위)

- Desktop 후보를 `0.0.2-beta.6`으로 올리고 startup fixture를 맞춘다. 기본 포함 Docling·AI agent manifest는 앱 semver를 사용하고 내용 식별은 revision을 유지한다(#1090 / PR [#1092](https://github.com/litzio/litzio/pull/1092)). 기존 테스트는 package.json의 version과 비교하므로 별도 고정 기대값을 추가하지 않는다.
- opt-in 실제 GitHub harness는 이미 같은 브랜드 Litzio `0.0.2-beta.5 → 0.0.2-beta.6`이다. 두 버전이 공개된 뒤에만 실행할 수 있다. CI local-feed fixture Stable `0.0.1 → 0.0.2`, Beta `0.1.0-beta.1 → 0.1.0-beta.2`는 유지한다.
- [#1093](https://github.com/litzio/litzio/pull/1093)과 [#1081](https://github.com/litzio/litzio/pull/1081)의 master 병합을 반영해 이번 Beta의 포함 변경 표와 한국어 Release 본문 초안을 확정했다. 게시 결과와 R1은 후속 기록 대상이다.
- 제외: tag 생성, release workflow 실행·게시, 준비 PR 병합, 로컬 앱 실행·설치·패키징, test:update·test:uninstall, 브라우저(Edge 포함), PATH·레지스트리·사용자 데이터 변경. 임시 폴더를 재귀 삭제하지 않는다.

## 남은 미검증·후속

같은 브랜드 Litzio `0.0.2-beta.5 → 0.0.2-beta.6` LIVE harness는 두 버전이 모두 공개되어 이제 실행 가능하다. 그러나 이 PC 설치 상태 보존 제약으로 실행하지 않았고 실제 GitHub 설치·업데이트는 **미실행·미검증**이다. IeumDoc beta.4 자동 업데이트·데이터 이전은 지원하지 않는다. 실제 Windows·IME·Codex/Copilot 옵션과 전체 권한·Docling 수동 확인 항목은 아래 공개 Release 본문에 그대로 남긴다.

### 제3자 고지 R1 처리

[#1076](https://github.com/litzio/litzio/issues/1076) / [#1081](https://github.com/litzio/litzio/pull/1081)의 R1은 2026-11-04 소유자 결정으로 다음과 같이 정리했다. 수정 릴리스는 고지를 보완한 beta.6(게시 2026-11-03T15:49:42Z)이다. 기존 beta.5 tag·자산·해시는 저장소 규칙(공개된 tag·자산은 재작성하지 않음)에 따라 바꾸거나 철회하지 않고, beta.5 Release 본문 맨 위에 "일부 제3자 고지가 빠져 있으니 beta.6을 사용하라"는 안내를 붙였다. beta.5 설치본은 자동 업데이트로 beta.6을 받을 수 있다. 별도 재감사는 하지 않았다. 원문 부재 등의 고지 예외·출처는 [고지 출처·예외](../../scripts/licenses/README.md)를 따르며 법적 적합성을 인증하지 않는다.
