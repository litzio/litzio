## 한국어 Release 본문 초안

서명 없는 Windows Beta 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows Beta. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.3-beta.5 Beta의 beta.4 이후 주요 변경입니다.

- **플러그인 설치와 업데이트.** 설정에서 설치 버전을 보고 로컬 폴더나 공개 GitHub 저장소에서 추가할 수 있습니다. 전체 또는 개별 플러그인의 업데이트를 확인해 적용할 수 있고, 원본 폴더를 수정하는 동안 설치된 판은 계속 실행됩니다. 기존 GitHub CLI 로그인이나 Host에 제공한 토큰을 재사용합니다.
- **큰 문서 작성과 저장.** 새 문서를 작성하는 계산을 작업 스레드로 옮겨 저장 중에도 백그라운드 서비스가 연결 확인에 응답하기 쉬워졌습니다. 연결 확인이 잠시 늦어져도 같은 백그라운드 서비스의 플러그인 화면과 요청을 유지합니다.
- **플러그인 문서 보기.** 화면이 탭 높이를 채울 수 있고, 자료와 대응하는 문서 블록을 연결 띠로 표시하고 선택할 수 있습니다. 제작자는 문서 블록을 자료와 같은 보이는 높이에 맞출 수 있습니다.
- **비서와 연결 표시.** 공급자 상태를 확인하는 동안에도 설정과 비서 입력을 사용할 수 있습니다. Copilot 답변은 해당 질문 카드에서 확인할 수 있습니다. 사이드바 연결 점을 정렬하고 서비스 실행 계정 설명을 설정으로 옮겼습니다.
- **편집기.** 알림 상자 종류 선택을 다섯 가지로 통일했습니다. 표의 행과 열은 손잡이 또는 셀의 우클릭 메뉴에서 추가할 수 있습니다.

**알려진 제약.** GitHub 플러그인은 공개 저장소만 지원합니다. 비로그인 API 요청은 시간당 60회로 제한되며 업데이트 확인과 적용은 수동입니다. 구형 플러그인 등록에는 원본 폴더를 다시 추가하고 신뢰해야 합니다. GitHub 로그인 재사용은 격리 Host에서 확인했고 설치형 Desktop에서는 확인하지 않았습니다. 큰 문서 응답성 측정은 작성 경로에 한정되며, 열기·일반 저장·검사에는 같은 측정을 하지 않았습니다.

개발 단계로 과거 데이터 하위 호환을 보장하지 않습니다. 비서의 변경 보기·되돌리기는 공급자 편집 이벤트가 있는 기존 UTF-8 파일(1 MiB 이하)에 한정되며 셸 직접 쓰기 등은 경로만 표시합니다. [현재 비서 한계](https://github.com/litzio/litzio/blob/v0.0.3-beta.5/docs/design/main-agent-v1.md#현재-한계)를 확인하세요.

Beta 설치본의 최초 기본 채널은 Beta이며 저장된 선택은 유지합니다. Beta 채널의 대상은 0.0.3-beta.5이며 Stable 채널에는 Beta를 제공하지 않습니다. 이번 Beta는 beta.yml만 제공합니다. 업데이트 전에 문서를 저장하세요. 실제 GitHub 설치·업데이트, SmartScreen·게시자 표시와 서명 배포는 미검증입니다.

전체 변경과 검증 범위는 [배포 기록](https://github.com/litzio/litzio/blob/v0.0.3-beta.5/docs/releases/v0.0.3-beta.5.md)에 있습니다.

## 검증과 게시 판단

`pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm docs:check`, Desktop 단위 검사 105건과 `git diff --check`가 통과했다. 로컬 패키징, 자산 검증, packaged·브라우저 회귀 및 실제 GitHub 설치·업데이트는 실행하지 않았다. 게시 단계에서는 태그가 가리키는 같은 커밋으로 Windows 패키지를 빌드하고 릴리스 자산·packaged 회귀·브라우저 회귀를 검증한다.
