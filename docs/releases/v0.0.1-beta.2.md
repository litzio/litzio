## Release notes

This Beta improves Windows release and update reliability. Stable checks now explain when no Stable release has been published. Beta updates remain available, and switching channels never downgrades the installed app. Downloads and installation still require the user's request, and unsaved documents prevent an update restart.

Maintainers can build and verify a release without publishing, publish a verified unsigned Beta, or publish with Authenticode signing. Existing releases and assets are never overwritten. Tags must belong to trusted master history; executable versions, metadata, blockmaps and uploaded asset hashes are checked before activation.

This installer is unsigned. Windows may display unknown-publisher or SmartScreen warnings. Checksums verify file integrity, not publisher identity. Document semantics, application identity, saved preferences and document locations are unchanged.

## Publication attempts — historical

Publication approval was granted on 2026-10-12. [PR #175](https://github.com/litzio/litzio/pull/175) and its [CI](https://github.com/litzio/litzio/actions/runs/38197637238) passed and merged; [master CI](https://github.com/litzio/litzio/actions/runs/38198188701) also passed. The first [manual verification run](https://github.com/litzio/litzio/actions/runs/38198195392) passed tag preflight and workspace checks but failed the Windows open-files browser fixture: its hard-coded `C:\tmp` parent was absent on the fresh runner, so media confinement returned 400 rather than the expected missing-file 404. The fixture now uses a prepared repository scratch directory and exact OS-native path matching; the expected 404 checks and production Host are unchanged. No beta.2 Release was created by that failed run.

The next [publication run](https://github.com/litzio/litzio/actions/runs/38200456526) passed the corrected open-files fixture but stopped before publication on Equation Escape focus and first-Saved unload observations (41/43 browser tests passed). The unchanged focused tests passed locally. Their assertions now wait for the exact expected focus/selection and observe only the held Save's first Saved commit; they neither set focus nor retry unload until it succeeds. Production code and the success conditions are unchanged. Browser diagnostics are retained on workflow failure. No beta.2 Release was created by this run either.

Independent lifecycle review then found that Equation's pending autofocus frame could run after Cancel while BaseUI retained the closing textarea, taking focus away from the editor before unmount. Apply, Cancel, a new Edit and unmount now cancel that pending frame without changing insertion timing. The focused Equation/update scenarios and Editor typecheck passed locally. Observation waits have explicit 30-second limits so a failed focus or unload observation cannot consume the full scenario timeout.

The [preceding Windows run](https://github.com/litzio/litzio/actions/runs/38201911416) was cancelled after its browser step stalled. Recovered logs showed `ERR_NO_BUFFER_SPACE` in Vite WebSocket/module requests: 40 browser tests passed (including Equation), two failed and Desktop updates was interrupted. The full browser suite now runs on Linux, the existing PR/push browser CI platform, while actual Electron/NSIS packaged and Stable/Beta install/update tests remain on Windows. Publication requires both jobs to pass. This run created no Release; publication and public-update acceptance were still pending at that stage.

Subsequent releases follow [Contributing](../../CONTRIBUTING.md#windows-desktop-builds-and-releases) and the opt-in [real GitHub Beta update](../test/README.md#real-github-beta-update). No signing certificate is needed for the restricted unsigned Beta mode. Published tags and assets must not be rewritten.
