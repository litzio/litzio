# Litzio v0.0.2-beta.2 — 배포·검증 기록

- Status: Historical
- Last verified: 2026-10-28 (공식 release workflow 첫 시도 성공과 공개 Release 본문 대조. 오케스트레이터의 공개 자산 익명 다운로드·해시 대조 결과 반영. 같은 SHA의 merge_group CI 성공·master push CI 실패를 구분해 기록. 실제 GitHub 설치·업데이트는 미실행·미검증).
- Scope: [#659](https://github.com/litzio/litzio/issues/659)의 Windows x64 unsigned Beta 준비·공개 결과. 직전 공개 기록은 [v0.0.2-beta.1](v0.0.2-beta.1.md)에 보존한다.

## 준비 단계 작업 계획 (당시 범위)

- 범위: Desktop 후보 버전을 `0.0.2-beta.2`로 올리고 실제 GitHub 업데이트 harness의 향후 대상을 `0.0.2-beta.1 → 0.0.2-beta.2`로 맞췄다. 공개 버전과 후보를 구분해 문서·색인 및 한국어 Release 본문 초안을 준비했다.
- 제외: 기능 코드 변경, tag 생성, release workflow 실행·게시, 병합과 로컬 설치·앱 실행. 실제 GitHub 업데이트는 소유자 결정으로 이번 릴리스에서 실행하지 않았다. 리뷰 agent·하위 agent를 사용하지 않았다.
- 완료: 대상 로컬 검사와 준비 PR의 필수 CI가 통과했고 `Refs #659` [PR #660](https://github.com/litzio/litzio/pull/660)을 오케스트레이터에 전달했다. 게시와 공개 자산 확인은 병합 후 오케스트레이터가 별도로 수행했다.
- 검증: frozen install, 문서·공백 검사, Desktop typecheck·단위 테스트와 가능하면 설치 없는 로컬 package·자산 검증을 계획했다. Stable·Beta local-feed 설치/업데이트, packaged·uninstall 검사는 disposable Windows CI에 맡겼다.

CI local-feed fixture는 Stable `0.0.1 → 0.0.2`, Beta `0.1.0-beta.1 → 0.1.0-beta.2`를 유지한다. 직전 준비 [PR #633](https://github.com/litzio/litzio/pull/633)처럼 공개 버전과 독립적인 테스트용 버전 쌍이다. harness는 현재 소스를 `LITZIO_TEST_VERSION`과 local-feed host로 각각 빌드하므로 과거 공개 자산을 쓰지 않는다. 실제 GitHub `LIVE` 경로만 공개 버전 쌍을 사용한다.

## 알려진 제한

- unsigned Beta이며 Authenticode 게시자 인증을 제공하지 않는다. 체크섬은 무결성 검증이며 SmartScreen·조직 보안 정책 경고가 나타날 수 있다. Stable은 미공개다.
- 개발 단계이므로 이전 Litzio 문서·복구 기록·설정의 하위 호환성과 자동 migration을 보장하지 않는다.
- 실제 GitHub `0.0.2-beta.1 → 0.0.2-beta.2` 설치·업데이트는 미검증이다. [실제 GitHub 검증 절차](../test/README.md#real-github-beta-update)와 CI local-feed 결과를 구별한다.
- 실제 Windows 창의 drag·더블클릭 최대화, 한글 IME 수식 입력, Desktop CLI 켜기/끄기는 별도 수동 확인 항목이다. 자동화·CI 성공으로 실제 사용자 환경 수용성을 판정하지 않는다. [수동 확인 경계](../test/README.md#manual-review)를 따른다.

## 공개 Release에 반영한 본문 (한국어)

Draft 초안을 바탕으로 오케스트레이터가 공개 Release에 반영한 본문이다. 기록 시점의 공개 본문과 대조했다.

> Litzio v0.0.2-beta.2는 Windows x64용 unsigned Beta입니다.
>
> **주요 변경**
>
> - 라이트 테마에서 페이지 모양 '평면'을 쓰면 창이 뜨지 않던 버그를 수정했습니다. 시작에 실패해도 숨은 프로세스만 남지 않도록 창 표시와 오류 안내도 보완했습니다. (#643)
> - 블록 수식을 문서 안의 넓은 입력면에서 미리보기를 보며 편집합니다. 인라인 수식 입력 공간도 넓혔습니다. (#637)
> - 코드블록 언어를 드롭다운에서 선택합니다. (#645)
> - 블록 선택 테두리와 호버 테두리를 맞췄고, 입력하는 동안에는 호버 테두리를 숨깁니다. (#469)
> - 로고와 LITZIO 제목 띠를 추가하고, 사이드바 머리를 문서 탭 높이에 맞췄습니다. (#647)
> - 붙여넣은 일반 이미지는 문서 이름과 순번으로 저장합니다. 드롭한 파일과 구체적인 원래 이름은 정리해서 유지합니다. 그림 속성에서 로컬 이미지 파일 이름을 바꾸면 참조도 함께 바뀝니다. (#652)
> - Mermaid 다이어그램을 문서 안에서 작성하고 미리 볼 수 있으며, 그림 번호·캡션·상호참조도 씁니다. 외부 서비스 없이 앱 안에서 렌더링합니다. (#651)
>
> **설치와 주의 사항**
>
> Assets의 `Litzio-Setup-0.0.2-beta.2.exe`를 사용합니다. Node.js나 pnpm은 따로 필요하지 않습니다.
>
> 코드 서명되지 않은 Beta이므로 Windows SmartScreen이나 조직 보안 정책 경고가 나타날 수 있습니다. 체크섬(SHA-512)은 파일 무결성 확인용이며, 게시자 인증을 대신하지 않습니다.
>
> 개발 단계이므로 이전 Litzio 문서·복구 기록·설정의 하위 호환성을 보장하지 않으며, 자동 migration도 제공하지 않습니다. 중요한 문서는 따로 백업해 주세요.
>
> 0.0.2-beta.1 → 0.0.2-beta.2 실제 GitHub 업데이트는 이번에 실행하지 않아 미검증입니다. CI의 local-feed 업데이트 검증 결과와는 구별합니다. 다음 항목은 별도로 수동 확인해야 합니다.
> - 실제 Windows 창 드래그와 더블클릭 최대화
> - 한글 IME로 수식 입력
> - Desktop CLI 켜기·끄기
>
