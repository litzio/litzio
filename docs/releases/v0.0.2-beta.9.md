## 준비 범위와 승인

- 소유자가 2026-11-09 이번 Beta 배포를 승인했다. 준비 PR은 버전·startup fixture·공개 beta.8 → beta.9 opt-in harness와 문서를 갱신한다.
- 태그 생성과 릴리스 workflow 실행은 오케스트레이터가 담당한다. 준비 에이전트는 병합하지 않는다.
- 로컬 패키징·test:packaged·test:update·test:uninstall은 실행하지 않는다. 필수 CI(Windows Desktop 포함)와 release workflow가 설치물 검증을 담당한다.
- 실제 공개 beta.6의 lifecycle helper 없는 설치본에서 출발하는 별도 CI 회귀는 고정 자산·해시를 유지한다.
- 최종 포함 기준은 PR [#1387](https://github.com/litzio/litzio/pull/1387)·[#1375](https://github.com/litzio/litzio/pull/1375)가 병합된 master `82415849520c06647d40c9cb2c0bcb5d0f7556bd`다. `v0.0.2-beta.8` 태그 이후 이 commit까지의 변경을 집계했다.

## 포함 변경 / 한국어 Release 본문

Litzio Windows x64 unsigned Beta입니다. beta.8 이후 변경을 정리했습니다.

- **플러그인 사용 개선:** 여러 파일 작업 패널, 연결 확인, 플러그인 아이콘, 입력 자동완성·안내값과 조회 폼의 **추가 조건** 접기, 표의 외부 링크·열 선택·결과 잘림 표시를 제공합니다. 설정의 플러그인 목록을 정리하고 처음 켤 때 등록한 코드에 대한 신뢰를 확인합니다(PR #1342·#1335·#1354·#1372·#1358·#1333·#1359·#1381·#1375).
- **문서 만들기:** 공용 문서 작성에서 이미지, 원본의 고정 번호, 번호 없는 그림·표와 긴 문서를 지원합니다. 작업 결과는 입력 파일 옆에 같은 이름으로 만들고, 이름이 겹치면 `-N`을 붙여 원본과 기존 결과를 보존합니다(PR #1318·#1378·#1385·#1380).
- **관리되는 생성 문서:** 생성 문서를 직접 편집할 때 재생성으로 내용이 바뀔 수 있음을 안내합니다. 공용 CLI에서 수정 기록을 저장하고 연결된 문서를 공식 경로로 다시 만들 수 있습니다. 저장할 때 Windows의 실제 파일명 표기도 유지합니다(PR #1387).
- **SDK 0.3.0:** 위 플러그인 기능과 공용 문서 작성·관리되는 생성 문서를 위한 SDK 0.3.0을 **beta.9와 함께 공개**합니다. SDK는 별도 npm 게시 없이 Host가 제공합니다. 기존 지원 계약과 기능별 최소 버전은 [SDK 버전 문서](../design/plugin-stage1-v1.md#sdk-버전과-호환-판정)를 따릅니다.
- **플러그인 기본 화면 유지:** 비서의 뷰 생성·저장·즐겨찾기와 문서 통계·차트를 제거했습니다. 플러그인이 제공하는 기본 화면·조회·작업 패널은 계속 사용할 수 있습니다(PR #1357).
- **파일 보기와 편집:** PDF를 보기 전용 탭으로 열고 일반 Markdown·텍스트 편집의 페이지 표면을 통일했습니다. 탐색기에서 파일·폴더 경로를 복사할 수 있습니다(PR #1339·#1344·#1338).
- **안정화와 관리:** 플러그인 설정 로딩 지연, 원격 탭 저장 순서·활성 탭 복원, OneDrive 폴더 표시와 비서 오류 처리를 개선했습니다. 앱과 로컬 Host 데이터의 완전 초기화를 추가했습니다. 설치·다운로드 검증도 보완했습니다(PR #1349·#1312·#1297·#1301·#1300·#1374).

커뮤니티 **Docling·Jira 플러그인은 앱 번들에 포함되지 않습니다.** 저장소 안의 소스는 별도 등록·신뢰·설정이 필요한 커뮤니티 플러그인이며, 외부 서비스가 필요합니다. [Docling 안내](../../community-plugins/docling/README.md)와 [Jira 안내](../../community-plugins/jira/README.md)의 사용·검증 범위를 따릅니다. Docling 0.0.5는 원본 PDF·변환 자료를 보존하면서 내부 수정 기록을 저장하고 문서를 다시 만듭니다. 검수 진행·승인 화면은 아직 제공하지 않습니다. Jira 0.0.5는 추가 조건 접기·입력 안내값과 추가 열 선택을 제공합니다.

## 알려진 제한

- **업데이트 전에 열려 있는 문서를 저장하세요.** 개발 단계이며 과거 데이터의 하위 호환·자동 migration을 제공하지 않습니다. 중요한 문서는 별도로 백업하세요.
- Host 인증은 아직 없습니다([#1145](https://github.com/litzio/litzio/issues/1145)). 웹 브라우저에서는 원격 Host를 등록할 수 없습니다.
- OneDrive는 로그인·동기화 상태를 판정하지 않습니다. 커뮤니티 플러그인의 실제 서비스 인증·변환 품질은 앱 CI 성공만으로 보장하지 않습니다.
- Windows x64 unsigned Beta이며 Stable은 아직 없습니다. 실제 GitHub beta.8 → beta.9 설치·업데이트는 **미실행·미검증**이며 CI 결과로 대신하지 않습니다.

## 업데이트 방법

- Litzio의 업데이트 채널을 Beta로 선택하고 업데이트를 확인하세요. beta.9 공개 후 beta.8에서 업데이트할 수 있습니다. 또는 [Releases](https://github.com/litzio/litzio/releases)에서 Windows 설치 파일을 내려받으세요.
- IeumDoc beta.4에서 Litzio로 자동 업데이트되지 않습니다. 새 설치가 필요하며 이전 앱의 데이터·설정·복구 기록은 이전되지 않습니다.
- daemon 프로토콜이 다르면 연결을 거부합니다. 해당 daemon과 일치하는 CLI로 종료한 뒤 원하는 버전으로 시작하세요. 제품 버전 차이는 경고합니다.
