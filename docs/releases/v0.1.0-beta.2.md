# Litzio v0.1.0-beta.2 — 릴리스 및 검증 기록

- Status: Historical
- Last verified: 2026-10-28 (공개 Release·master/tag·release CI 성공, 세 자산의 익명 다운로드·SHA-256 및 installer SHA-512 일치, 한국어 Release 본문과 다음 게시의 environment 보호 규칙 확인. 실제 GitHub 업데이트는 아래 예외대로 미검증).
- Scope: Windows x64 Desktop unsigned Beta [v0.1.0-beta.2](https://github.com/litzio/litzio/releases/tag/v0.1.0-beta.2)의 공개·검증 근거. Stable 공개는 계속 보류한다.

## 철회 안내 (2026-10-28, #632)

기능 변화 없는 [v0.0.2-beta.1](v0.0.2-beta.1.md)의 신규 공개 자산 검증 후 소유자 승인으로 이 버전의 Release·첨부 자산·원격 tag를 삭제했다. 이 문서의 Release 링크는 삭제된 과거 게시 위치를 가리키는 역사적 링크이며 현재 다운로드 경로가 아니다. 현재 다운로드는 [v0.0.2-beta.1 Release](https://github.com/litzio/litzio/releases/tag/v0.0.2-beta.1)를 사용한다. 원래 tag의 [소스 commit](https://github.com/litzio/litzio/commit/26fbee160f7c3c108264e4397850bebb0eaa5413)은 보존한다. 아래 날짜·해시·CI·업데이트 결과는 철회 전 당시 사실이며 새 버전의 검증으로 바꾸지 않았다.

## 범위와 완료 조건

게시 후 마무리 범위는 한국어 GitHub Release 본문, 공개 버전 안내·검증 기록 갱신과 소유자가 요청한 다음 릴리스의 별도 environment 승인 제거다. 완료 조건은 공개 파일의 익명 다운로드·해시 일치, 한국어 본문 반영, `desktop-release`의 reviewer 대기 제거와 `master` 제한 유지 확인, 문서 검사·필수 PR CI·독립 검토를 거친 병합이다. 앱·자산·공개 tag는 변경하지 않으며 실제 GitHub 업데이트 검사는 아래 승인된 예외를 유지한다.

소유자는 Desktop `0.1.0-beta.2`, `unsigned-beta` 모드와 한국어 릴리스 노트를 승인했다. 이 릴리스는 `v0.1.0-beta.1` 이후 master에 병합된 사용자 변경을 묶는다. 후보 준비의 조사 기준은 beta.1 태그 `b11775446786b6fc973c2b9d6953c8ac38989b4c`부터 master `370ecd74fa75373c783ff443273b40ded2b0f3f4`까지다. `git log v0.1.0-beta.1..origin/master`와 `gh pr list --state merged --base master --search 'merged:>=2026-10-25'` 및 아래 PR 본문을 대조했다. 중간 UI가 후속 PR에서 대체된 경우 최종 동작을 적었다. 후보 PR [#628](https://github.com/litzio/litzio/pull/628) 이후 CLI 정리 수정 [#630](https://github.com/litzio/litzio/pull/630)을 포함한 최종 게시 commit은 `26fbee160f7c3c108264e4397850bebb0eaa5413`이다.

후보 PR #628은 버전·기존 업데이트 검사 대상·검증 명령·릴리스 기록과 색인을 변경했다. 새 기능, migration, updater/installer 구현 변경은 포함하지 않았다. 기록 작성 후 로컬 typecheck·문서·Desktop 단위 테스트·버전 일치를 확인했고, 패키징·실제 설치/업데이트·packaged 검사는 Windows CI에서 실행했다. 후보 PR 작업과 후속 병합·태그·게시 작업의 근거는 아래에서 구분한다.

게시 작업은 병합 후 별도로 수행했다. 검증된 master 태그에서 수동 `unsigned-beta` workflow를 실행했고, 소유자가 agent의 게시 승인을 명시적으로 요청하여 `desktop-release` 승인이 처리됐다. 2026-10-28 05:28:15 KST에 Prerelease로 공개됐다. 후속 마무리에서 한국어 본문과 공개 버전 안내를 갱신했다. 다음 게시부터 별도 수동 승인을 하지 않겠다는 소유자 결정으로 environment의 required reviewer만 제거했으며, `master` branch 배포 제한·수동 workflow 실행·기존 검증과 서명 조건은 유지한다.

소유자 결정으로 **실제 GitHub 공개 `0.1.0-beta.1 → 0.1.0-beta.2` 업데이트 검사는 이번 릴리스에서 실행하지 않으며 미검증으로 남긴다.** 일반 발행 순서의 이 검증 단계에 대한 이번 릴리스의 명시적 예외다. CI의 local-feed 설치/업데이트 회귀는 유지하며, 그 성공을 실제 GitHub 전달 성공으로 표시하지 않는다.

## 릴리스 노트

### 호환성과 동작 변경

- **개발 단계이므로 beta.1에서 저장한 문서·복구 기록·설정과의 하위 호환성을 보장하지 않습니다.** 기존 데이터가 거부되거나 다시 저장할 때 표현이 달라질 수 있습니다. 자동 migration을 제공하지 않습니다. `litzio: 1` 표식은 유지되지만 이 표식이 이전 데이터 전체의 호환성을 보장하지는 않습니다([#587](https://github.com/litzio/litzio/pull/587), [문서 계약](../design/document-support-v1.md)).
- 캡션·Label이 없어도 모든 표에 공식 번호를 부여합니다. 일반 GFM 표도 읽을 수 있으며 저장하면 `{table}` directive가 됩니다. 앞의 무캡션 표도 번호에 포함되므로 뒤 표의 표시 번호가 달라질 수 있습니다. 지원 표 입력은 GFM과 정확한 `{table}` directive이며, `name`/`label` 외 옵션이나 `{csv-table}`·`{list-table}`는 거부합니다([#592](https://github.com/litzio/litzio/pull/592)).
- 빈 안내 상자·인용·목록 항목·수식과 새 빈 표를 저장하고 다시 열 수 있습니다. 의미 데이터 없이 공백만 있는 안내 상자·인용·목록 항목도 빈 요소로 저장하며, Editor는 저장되지 않는 안내 문구를 보여 줍니다([#589](https://github.com/litzio/litzio/pull/589), [#623](https://github.com/litzio/litzio/pull/623), [#626](https://github.com/litzio/litzio/pull/626)).
- 최소 640px의 데스크톱급 창과 키보드·포인터 입력을 지원 대상으로 정리했습니다([ADR-0010](../adr/0010-supported-viewport-and-input.md), [#610](https://github.com/litzio/litzio/pull/610)).

### Editor

- 탐색기형 사이드바에서 폴더별 새 문서와 메뉴를 제공합니다. Windows 제목 표시줄을 앱 상단 바에 통합하고 기본 창 버튼을 유지합니다. 얇아진 문서 탭은 하단 포인트 표시로 활성 문서를 구분합니다([#614](https://github.com/litzio/litzio/pull/614), [#591](https://github.com/litzio/litzio/pull/591)).
- 설정을 분류가 있는 전용 화면으로 바꾸고 System / Light / Dark 테마, 종이 / 평면 페이지 모양, 여섯 가지 포인트 색 견본을 제공합니다. 선택 세그먼트와 문서·명령 찾기 화면의 경계도 정돈했습니다([#596](https://github.com/litzio/litzio/pull/596), [#598](https://github.com/litzio/litzio/pull/598), [#599](https://github.com/litzio/litzio/pull/599), [#616](https://github.com/litzio/litzio/pull/616), [#618](https://github.com/litzio/litzio/pull/618), [#621](https://github.com/litzio/litzio/pull/621)).
- 개요 패널에서 개요·표·그림 목록을 전환합니다. 표와 그림의 공식 번호·캡션을 보고 해당 위치로 이동할 수 있습니다([#619](https://github.com/litzio/litzio/pull/619)).
- 문서 설정은 제목 위의 접힘 블록으로 옮겼습니다. 제목 번호·상호 참조 표기·참고문헌 파일을 요약하고 펼쳐서 변경할 수 있습니다. 참고문헌 선언과 인용이 모두 없으면 References 영역을 숨깁니다([#607](https://github.com/litzio/litzio/pull/607), [#482](https://github.com/litzio/litzio/pull/482)).
- 파일 우클릭 메뉴에서 삭제와 이름 변경을 지원합니다. Desktop 삭제는 휴지통을 사용합니다. 참조된 이미지의 이름을 바꾸면 해당 열린 폴더의 문서 Figure 경로도 갱신하며, 미저장 참조 문서는 먼저 저장하도록 안내합니다([#601](https://github.com/litzio/litzio/pull/601), [#609](https://github.com/litzio/litzio/pull/609)).
- 미주는 기본 읽기 전용으로 표시합니다. 선택 후 Enter 또는 더블클릭으로 한 정의를 편집하고 Escape나 포커스 이동으로 마칩니다([#608](https://github.com/litzio/litzio/pull/608)).
- 그림·표 캡션을 본문에서 직접 편집하고, 속성은 선택 후 Enter나 더블클릭으로 엽니다. 속성 폼의 Ctrl/Cmd+Enter는 적용 버튼과 같은 동작을 합니다. 표 행·열은 가벼운 핸들로 조작하고 블록 메뉴에서 인접 블록 이동을 제공합니다([#563](https://github.com/litzio/litzio/pull/563), [#570](https://github.com/litzio/litzio/pull/570), [#585](https://github.com/litzio/litzio/pull/585), [#586](https://github.com/litzio/litzio/pull/586), [#530](https://github.com/litzio/litzio/pull/530), [#523](https://github.com/litzio/litzio/pull/523)).
- 표 칸의 코드·수식에 포함된 파이프와 백슬래시가 저장 후에도 원문대로 유지됩니다([#625](https://github.com/litzio/litzio/pull/625)).
- 새 문서 진입점, 읽어 온 폴더 목록 새로고침, 문서·명령 찾기 안내와 검색 순위, 인용 키 후보 목록, 그림 선택 미리보기를 개선했습니다([#567](https://github.com/litzio/litzio/pull/567), [#561](https://github.com/litzio/litzio/pull/561), [#572](https://github.com/litzio/litzio/pull/572), [#564](https://github.com/litzio/litzio/pull/564), [#484](https://github.com/litzio/litzio/pull/484)).
- 실행 취소·다시 실행을 명령 센터에서 제공하고 단축키 안내를 보완했습니다. 한글 IME의 불투명 키 이벤트 처리와 한국어 어절 단위 줄바꿈을 개선했습니다. 실제 Windows 한글 IME 수동 확인은 아래 제한을 따릅니다([#485](https://github.com/litzio/litzio/pull/485), [#481](https://github.com/litzio/litzio/pull/481), [#508](https://github.com/litzio/litzio/pull/508)).

### Desktop CLI

- 설정의 명령줄 도구(CLI)를 직접 켜면 별도 Node.js 설치 없이 `litzio`를 실행할 수 있습니다. 기본값은 꺼짐이며 새 터미널을 열어 사용합니다. 설치·업데이트가 자동으로 PATH에 등록하지 않습니다. `litzio --version`은 버전과 빌드 commit을 표시합니다([#627](https://github.com/litzio/litzio/pull/627)).
- CLI `update-media-references`는 Core의 Figure 경로 변경 연산을 제공합니다. 폴더 순회와 이미지 파일 자체의 이름 변경은 이 명령의 범위가 아닙니다([#609](https://github.com/litzio/litzio/pull/609)).
- CLI 끄기·제거 후 소유 파일을 정리하고 bin 폴더가 비어 있으면 삭제합니다. 사용자 파일이 있으면 보존합니다. 이 수정으로 release workflow의 Stable 검사 다음 Beta 설치 검사가 실패하던 문제를 해결했습니다([#630](https://github.com/litzio/litzio/pull/630)).

## 호환성 확인 근거

beta.1 태그의 `packages/core`를 별도 임시 경로로 추출하고 현재와 같은 고정 의존성으로 실행했다. 두 버전의 public Core API만 사용했다. beta.1의 `insertTable(createDocument(), 1, [['A', 'B'], ['1', '2']])` → `serialize` 결과를 현재 Core의 `parse` → `serialize`에 전달했다.

beta.1 저장 본문:

```markdown
| A | B |
| - | - |
| 1 | 2 |
```

beta.2 후보 재저장 본문:

```markdown
:::{table}

| A | B |
| - | - |
| 1 | 2 |
:::
```

양쪽 모두 앞에 `litzio: 1` frontmatter가 있다. 현재 Core가 beta.1 저장 문서를 수용했고 셀 텍스트가 같으며, 재파싱 후 재직렬화가 동일함을 단언으로 확인했다. 이는 **저장 표현이 바뀌는 한 사례**다. 모든 beta.1 문서의 수용 여부, 거부되는 beta.1 저장 사례, 과거 복구 기록 복원과 설정 보존은 이번에 확인하지 않았다. 전체 호환성이나 자동 복구 성공으로 확대하지 않는다.

## 알려진 제한과 수동 미검증

- installer는 unsigned이므로 알 수 없는 게시자·SmartScreen 경고가 나타날 수 있다. 체크섬은 무결성을 확인하며 게시자 신원을 인증하지 않는다. Stable은 계속 미공개다([ADR-0004](../adr/0004-desktop-host-distribution.md)).
- 실제 GitHub beta.1→beta.2 업데이트는 소유자 결정으로 이번 릴리스에서 **미검증**이다. local-feed CI는 공개 전달·SmartScreen 평판을 보장하지 않는다.
- 이 후보 준비 세션에서는 실제 Windows 창 이동·더블클릭 최대화·최대화 여백·테마 변경 시 창 버튼 색·작업 표시줄/Alt+Tab 제목을 수동 확인하지 않았다([#614](https://github.com/litzio/litzio/pull/614), [Desktop 수동 범위](../design/desktop-distribution-v1.md#integrated-windows-title-bar-605)).
- 일반 사용자 환경의 Desktop CLI 켜기 → 새 터미널 실행 → 끄기, 업데이트 후 실행, 제거 후 정리, 장시간 `serve`와 실제 콘솔 Ctrl+C는 수동 미검증이다. CI의 격리 설치 검증과 구별한다([#627](https://github.com/litzio/litzio/pull/627)).
- 실제 Windows 한글 IME의 물리 키보드 입력·조합·Undo/Redo는 이 세션에서 수동 검증하지 않았다. 합성 이벤트 회귀를 실제 IME 확인으로 표시하지 않는다([#481](https://github.com/litzio/litzio/pull/481), [#562](https://github.com/litzio/litzio/pull/562), [수동 검토](../test/README.md#manual-review)).
- 원본 파일 자동 저장은 제공하지 않는다. 로컬 복구와 별개로 명시적으로 저장해야 한다([#297](https://github.com/litzio/litzio/issues/297)). 이미지 이름 변경과 여러 문서 갱신은 프로세스/OS 중단까지 원자적으로 보장하지 않는다([#609](https://github.com/litzio/litzio/pull/609)).

Release controller는 이 파일을 자동으로 읽지 않고 GitHub 자동 노트를 생성하므로, 게시 후 위 릴리스 노트·알려진 제한과 최종 검증 요약을 한국어 본문으로 별도 반영했다. 공개 자산과 tag는 후속 문서 작업에서 변경하지 않았다.

## 게시 중 실패와 태그 이동

최초 [release 실행 40556505792](https://github.com/litzio/litzio/actions/runs/40556505792)은 CLI 해제·제거 후 빈 bin 폴더가 남아 다음 채널 설치 검사를 막아 실패했다([#629](https://github.com/litzio/litzio/issues/629)). #630으로 소유 파일 제거 뒤 빈 폴더만 삭제하도록 수정하고 master CI를 통과했다. 소유자가 승인한 A안에 따라, 같은 tag의 공개 Release와 Draft가 모두 없는 것을 확인한 뒤 미게시 `v0.1.0-beta.2` tag를 `b5ce8d5162e0d66c1e98e540bcefafe7d7e7e7bc`에서 `26fbee160f7c3c108264e4397850bebb0eaa5413`으로 옮겨 재실행했다. 공개 후 tag나 자산을 재작성한 사례가 아니며, 일반 발행에서 이미 공개된 tag와 자산을 바꾸지 않는 규칙은 유지한다.
