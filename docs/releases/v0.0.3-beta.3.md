## 한국어 Release 본문

게시된 한국어 본문을 API로 직접 읽어 아래에 기록했다. 자동 생성된 "What's Changed" 목록은 없으며 이번 작업에서 본문을 수정하지 않았다.

서명 없는 Windows Beta 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows Beta. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.3-beta.3 Beta의 beta.2 이후 주요 변경입니다. 이번 판은 화면을 고른 판입니다.

- **한 가지 디자인 규칙:** 화면의 글씨를 역할(화면 제목, 범주 제목, 구역 이름, 묶음 이름, 항목 이름, 본문, 보조)로 정리했습니다. 앱의 기본 글씨는 14px, 가장 작은 글씨는 12px입니다. 문서 본문의 글씨는 바뀌지 않습니다.
- **본체와 플러그인이 함께 쓰는 부품:** 이름과 값 한 줄, 묶음, 구역 머리, 상태 표시가 하나의 부품이 되어 설정 화면과 플러그인 화면이 같은 모양으로 보입니다. 이름은 왼쪽 선, 값과 버튼은 오른쪽 끝 선에 놓입니다.
- **설정 화면:** 다섯 범주를 같은 구조로 정리했습니다. 정보·업데이트는 "로컬 백그라운드 서비스"와 "업데이트"로 다시 묶었고, 릴리스 채널은 선택 상자 하나로 바뀌었습니다. 상태는 점과 말로 보입니다(예: 실행 중, 사용 가능).
- **폴더·파일 선택 창:** Windows의 파일 선택 창과 같은 방식으로 바뀌었습니다. 클릭은 선택, 두 번 클릭은 폴더로 들어가기 또는 파일 확정입니다. 이름·수정한 날짜·크기로 정렬하고, 뒤로·앞으로·위로 이동하며, 경로는 `Ctrl+L`로 직접 입력할 수 있습니다. 폴더 열기, 이미지 고르기, 플러그인 화면의 파일 고르기가 같은 창을 씁니다.
- **플러그인 화면:** 화면 위쪽에 이름·설명·상태·주된 동작이 있는 고정 머리가 생겼습니다. 단계 표시, 빈 상태 안내, 진행 표시, 선택 상자, 확인 창, 표의 행 선택, 일반 파일 고르기를 부품으로 제공합니다. 데이터 표는 열 제목과 값이 같은 선에 놓이고 키보드 focus가 줄에 표시됩니다.
- **탐색기와 비서 패널:** 두 패널의 머리가 같은 모양이며 문서 탭 줄과 높이가 맞습니다. 비서의 도구 호출 줄은 진행 중을 도는 표시, 실패를 빨간 점으로 보입니다.
- **색과 움직임:** 정상·연결됨 상태는 초록으로 표시합니다. 버튼의 색 변화, 대화상자·메뉴·알림의 등장에 짧은 움직임(0.25초)을 더했습니다. Windows에서 애니메이션을 끄면 움직이지 않습니다.
- **편집 수정:** 그림·표·수식·절의 속성 입력칸에 값을 넣다가 본문을 클릭하면 커서가 다른 블록으로 돌아가던 문제를 수정했습니다.
- **정리:** 삭제된 기능의 문서와 캡처, 쓰이지 않는 코드를 정리했습니다.

알려진 제약: 대화상자·메뉴를 닫는 움직임이 끝나기 전(약 0.25초 안)에 친 글자는 닫히는 창이 받습니다. 명령 센터는 닫는 즉시 사라집니다. 검색, 우클릭 메뉴, 여러 개 선택, 창 크기 조절은 새 파일 선택 창에 아직 없습니다.

개발 단계로 과거 데이터 하위 호환을 보장하지 않습니다. 비서의 변경 보기·되돌리기는 공급자 편집 이벤트가 있는 기존 UTF-8 파일(1 MiB 이하)에 한정되며 셸 직접 쓰기 등은 경로만 표시합니다. [현재 비서 한계](https://github.com/litzio/litzio/blob/v0.0.3-beta.3/docs/design/main-agent-v1.md#현재-한계)를 확인하세요.

Beta 설치본의 최초 기본 채널은 Beta이며 저장된 선택은 유지합니다. Beta 채널에서는 0.0.3-beta.3을 받을 수 있으며 Stable 채널에는 Beta를 제공하지 않습니다. 이번 Beta는 beta.yml만 제공합니다. 업데이트 전에 문서를 저장하세요. 실제 GitHub 설치·업데이트와 SmartScreen 표시는 아직 검증하지 않았습니다.

전체 변경과 검증 범위는 [배포 기록](https://github.com/litzio/litzio/blob/master/docs/releases/v0.0.3-beta.3.md)에 있습니다.

## 검증과 게시 판단

아래는 준비 PR #1702 당시의 검증 기록이다. 현재 게시 결과는 위 공개 결과를 따른다.

첫 후보 `04f332e3`의 로컬 frozen install → 공식 package → verify-release가 통과했다. installer·채널 manifest·PE 버전·blockmap 검증이며 설치 파일은 실행하지 않았다. Desktop 단위 검사 105/105, Desktop typecheck, docs:check와 git diff --check도 통과했다. 감시 대상 밖 checkout에서 Host 데이터·비서 작업·비서 설정·daemon·플러그인 설정·ResetGuard 여섯 경로 및 Electron profile·cache·TEMP/TMP를 격리한다. 전체 packaged는 로컬에서 실행하지 않았다. 기준 master `d5ca06721c51f6cd87ed8d8234a49aa47faf3b2f`와 같은 SHA의 [merge queue 43840605385](https://github.com/litzio/litzio/actions/runs/43840605385)에서 Windows Desktop package/verify/packaged와 필수 aggregate 성공을 직접 확인했다. Desktop job은 skip되지 않았으며 clean package·installer/update metadata 검증·test:packaged 단계가 각각 성공했다. 게시 전 release workflow의 전체 검증도 위 verify·게시 실행에서 완료됐다.

최종 master 반영 후보 `82e67935197045d89a3c3adbf874cef8b49843f7`에서 감시 대상 밖 checkout의 여섯 Host 경로·Electron profile·cache·TEMP/TMP를 격리해 frozen install → 공식 package → `verify-release.ts --tag v0.0.3-beta.3`를 다시 실행했고 모두 통과했다. installer·manifest·PE 버전·blockmap 검증이며 설치 파일은 실행하지 않았다. 이후 변경은 이 검증 기록뿐이다. 준비 PR의 최종 head CI 성공 뒤 master에 병합됐고 tag·release workflow·게시는 통합 담당자가 수행했다. 직접 시작한 검증 프로세스는 종료됐고 checkout과 산출물은 보존했다.

준비 단계 로컬 실제 AI 호출 0회. 로컬 설치·업데이트·제거·전체 packaged·브라우저·실제 Electron UI는 미실행·미검증이다. 이전 beta.2의 native 너비 1440 기대/1439 관찰 제한은 이 후보에서 재검증하거나 해결하지 않았다. 준비 단계에 기록한 Windows daemon 시작 지연(#1511)과 제거 후 실행 파일 잔존(#1231)의 간헐 실패는 원인 미확정으로 남긴다. Command center 검사는 Escape 뒤 100ms를 두는 소유자 승인 기준이며 같은 이벤트 안의 즉시 복귀를 보장하지 않는다(#1700, #1701).
