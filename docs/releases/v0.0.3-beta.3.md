## 한국어 Release 본문 초안

서명 없는 Windows Beta 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows Beta. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.3-beta.3 Beta의 beta.2 이후 주요 변경입니다. 게시용 초안이며 아직 게시하지 않았습니다.

- 본체와 플러그인의 글씨·줄·묶음·구역 머리·상태 표현을 공용 부품으로 정리했습니다. 플러그인의 단계·빈 상태·진행·선택·확인·파일 선택을 개선했습니다.
- 폴더·파일 선택을 목록 중심으로 재구성하고 설정의 상태 설명과 릴리스 채널 선택을 정리했습니다.
- 탐색기와 비서 패널의 머리, 비서 도구 상태 표시를 정리했습니다. 정상 상태는 초록 색으로, 진행 중은 도는 표시로 구별합니다.
- 조작과 겹침 화면의 움직임에 250ms 규칙을 적용하며 운영체제의 움직임 줄이기를 따릅니다.
- 속성 폼 작업 뒤 본문을 클릭했을 때 커서가 사라지는 문제를 수정했습니다. 삭제된 기능의 낡은 문서·캡처와 죽은 코드를 정리했습니다.

대화상자·메뉴를 닫은 직후 기계 속도로 입력하면 focus 복귀 전에 문자가 이전 control에 들어갈 수 있습니다. Command center 검사는 Escape 뒤 100ms를 두는 소유자 승인 기준이며 같은 이벤트 안의 즉시 복귀를 보장하지 않습니다(#1700, #1701). Windows daemon 시작 지연(#1511)과 제거 후 실행 파일 잔존(#1231)의 간헐 실패는 원인 미확정입니다.

개발 단계로 과거 데이터 하위 호환을 보장하지 않습니다. 업데이트 전에 문서를 저장하세요. Beta 설치본의 최초 기본 채널은 Beta이며 저장된 선택은 유지합니다. Stable 채널에는 Beta를 제공하지 않습니다. 실제 GitHub 설치·업데이트, SmartScreen·게시자 표시와 signed delivery는 미실행·미검증입니다.

## 검증과 게시 판단

첫 후보 `04f332e3`의 로컬 frozen install → 공식 package → verify-release가 통과했다. installer·채널 manifest·PE 버전·blockmap 검증이며 설치 파일은 실행하지 않았다. Desktop 단위 검사 105/105, Desktop typecheck, docs:check와 git diff --check도 통과했다. 감시 대상 밖 checkout에서 Host 데이터·비서 작업·비서 설정·daemon·플러그인 설정·ResetGuard 여섯 경로 및 Electron profile·cache·TEMP/TMP를 격리한다. 전체 packaged는 로컬에서 실행하지 않았다. 현재 master `0b73de96d6b531f4ef8d34a5920104db8f37331f`의 [merge queue 43833563534](https://github.com/litzio/litzio/actions/runs/43833563534)에서 Windows Desktop package/verify/packaged와 필수 aggregate 성공을 직접 확인했다. 이는 #1696 반영 뒤의 최종 기준 master 증거를 대신하지 않는다.

실제 AI 호출 0회. 설치·업데이트·제거·전체 packaged·브라우저·실제 Electron UI는 미실행·미검증이다. 이전 beta.2의 native 너비 1440 기대/1439 관찰 제한은 이 후보에서 재검증하거나 해결하지 않았다.
