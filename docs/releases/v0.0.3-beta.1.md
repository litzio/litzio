## 준비 범위와 승인

- 소유자가 이 Beta의 준비와 배포를 승인했다. 준비 PR은 병합·tag 생성/게시·release workflow 실행·GitHub Release 생성을 하지 않는다.
- `git log v0.0.2..HEAD --oneline --merges`로 확인한 집계 기준은 `ff8b4f976d86ff1aa4fbf8a7b976094ba2fda22e`이다. 아래 7개 병합 외 미병합 작업은 포함하지 않는다.
- 준비 PR CI → 오케스트레이터 병합·queue Windows 검사 → 검증된 master commit에 `v0.0.3-beta.1` tag → master에서 tag와 `mode=unsigned`로 수동 실행 → 전체 검사 성공 후 게시 → 공개 자산·한국어 본문·실제 업데이트 검증 여부 기록 순서다. 게시 전 실제 environment의 master 제한을 확인한다.

## 포함 변경 / 한국어 Release 본문 초안

서명 없는 Windows Beta 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows Beta. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.3-beta.1 Beta의 0.0.2 Stable 이후 주요 변경입니다.

- **비서가 원본 문서를 바로 수정합니다:** 기존 사본 → [적용] 방식을 제거했습니다. 남아 있던 대기 사본은 옮겨지지 않습니다(PR #1569, #1565 묶음).
- **외부 변경 자동 반영:** 미저장 편집이 없는 열린 문서는 비서 등 외부에서 저장한 변경을 자동 반영합니다(PR #1568).
- **비서 변경 보기·되돌리기:** 비서가 남긴 문서 변경을 확인하고 되돌릴 수 있습니다. 셸이 직접 바꾼 파일과 daemon 재시작 이전 변경은 대상이 아니며 일부 diff에는 버튼을 제공하지 않습니다(PR #1570).
- **PowerShell 진단 안내:** Store 방식 PowerShell 7의 실행 문제 진단 안내를 보완했습니다. 실제 Store 설치 환경은 미검증입니다(PR #1567).
- **결정과 검증 기록:** 범용 에이전트 비서 결정을 ADR-0021에 기록했습니다(PR #1566). Stable 공개 기록을 보존하고(PR #1563), reset-helper 테스트가 완성된 relaunch marker를 기다리도록 보완했습니다(PR #1564, 제품 동작 변경 없음).

Beta 설치본의 최초 기본 채널은 Beta입니다. 저장된 채널 선택은 유지됩니다. Beta 채널에서는 0.0.2 Stable보다 높은 semver인 0.0.3-beta.1을 받을 수 있으며 Stable 채널에는 Beta를 제공하지 않습니다. 이번 Beta는 beta.yml만 제공합니다. 실제 GitHub 설치·업데이트는 아직 미검증입니다.

## 확인 범위와 남은 검증

- 로컬 통과: `pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm docs:check`, Desktop 단위 테스트 109개, `git diff --check`.
- 로컬 `pnpm --filter @litzio/desktop package`는 Electron 해제 뒤 generated output 이름 변경에서 Windows `EPERM`으로 실패했다. 해당 출력의 ACL은 쓰기 허용이고 작업 소유 앱 프로세스는 없었으나 직접 이름 변경도 거부됐다. 잠금 주체는 미확정이며 반복 빌드나 timeout 변경으로 덮지 않았다.
- `verify-release.ts --tag v0.0.3-beta.1`과 `test:packaged`도 실행했지만 선행 패키징 실패로 설치 파일·manifest·실행 파일이 없어 실패했다. 로컬 후보 검증은 완료되지 않았으며 queue/release Windows 검사가 필요하다.
- 기존 `offerFor` 규칙으로 Beta에서 `0.0.2 → 0.0.3-beta.1` 제공 및 Stable에서 거부를 실제 함수 호출로 확인했다. 이것은 실제 GitHub 전달 결과가 아니다.
- 공개 설치본 회귀 기준은 최신 `0.0.2` Stable로 갱신한다. GitHub API digest와 기존 Stable 기록의 설치 파일 SHA-256을 대조했다. 회귀는 저장된 Stable 채널을 유지한 채 후보 NSIS 설치·보존을 검사하며 릴리스 CI 전용이다. helper 없는 최초 업데이트는 검증하지 않는다.
- `test:update`, `test:uninstall`, 공개 설치본 회귀 및 `test:update:github`는 로컬 미실행이다. 작업용 PC의 설치 상태를 바꾸지 않는다. CI local-feed·공개 설치본 결과와 실제 GitHub 업데이트를 구분한다.
- Store PowerShell 7 실환경, SmartScreen 및 signed delivery는 미검증이다.
