## 한국어 Release 본문

게시 뒤 적용된 현재 본문을 `gh release view`로 대조했다. 첫 줄 unsigned 경고를 유지한다.

서명 없는 Windows Beta 배포입니다. Windows에 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. SHA-512는 파일 무결성을 확인하며 게시자를 인증하지 않습니다. Unsigned Windows Beta. Windows may show publisher or SmartScreen warnings. SHA-512 checks file integrity; it does not authenticate the publisher.

Litzio v0.0.3-beta.1 Beta의 0.0.2 Stable 이후 주요 변경입니다.

- **비서가 원본 문서를 바로 수정합니다:** 기존 사본 → [적용] 방식을 제거했습니다. 비서는 문서를 텍스트로 바로 고친 뒤 스스로 검사합니다. 남아 있던 대기 사본은 옮겨지지 않습니다(PR #1569).
- **외부 변경 자동 반영:** 미저장 편집이 없는 열린 문서는 비서 등 외부에서 저장한 변경을 자동으로 보여 줍니다. 미저장 편집이 있는 문서는 이전처럼 알림과 확인을 거칩니다(PR #1568·#1572).
- **비서 변경 보기·되돌리기:** 대화의 파일 변경 항목에서 비서가 바꾼 내용을 비교하고 되돌릴 수 있습니다. 셸 명령이 직접 바꾼 파일과 daemon 재시작 이전의 변경은 대상이 아니며, 변경 정보를 정확히 대조할 수 없는 경우에는 버튼을 제공하지 않습니다(PR #1570).
- **PowerShell 진단 안내:** Microsoft Store 방식의 PowerShell 7만 설치된 PC에서 비서의 셸 실행이 막힐 수 있음을 AI 설정 진단에 표시하고 해결 방법을 안내합니다. 실제 Store 설치 환경에서는 검증하지 못했습니다(PR #1567).
- **결정 기록:** 비서를 범용 에이전트로 운영하는 결정을 ADR-0021에 기록했습니다(PR #1566).

Beta 설치본의 최초 기본 채널은 Beta입니다. 저장된 채널 선택은 유지됩니다. Beta 채널에서는 0.0.2 Stable보다 높은 0.0.3-beta.1을 받을 수 있으며 Stable 채널에는 Beta를 제공하지 않습니다. 이번 Beta는 beta.yml만 제공합니다. 실제 GitHub에서의 설치·업데이트는 아직 검증하지 않았습니다.

## 확인 범위와 남은 검증


- 로컬 통과: `pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm docs:check`, Desktop 단위 테스트 109개, `git diff --check`.
- 로컬 `pnpm --filter @litzio/desktop package`는 Electron 해제 뒤 generated output 이름 변경에서 Windows `EPERM`으로 실패했다. 해당 출력의 ACL은 쓰기 허용이고 작업 소유 앱 프로세스는 없었으나 직접 이름 변경도 거부됐다. 잠금 주체는 미확정이며 반복 빌드나 timeout 변경으로 덮지 않았다.
- `verify-release.ts --tag v0.0.3-beta.1`과 `test:packaged`도 실행했지만 선행 패키징 실패로 설치 파일·manifest·실행 파일이 없어 실패했다. 로컬 후보 검증은 완료되지 않았고 재시도하지 않았다. 이후 패키징·자산 검증·packaged 회귀는 merge queue와 release workflow Windows job에서 통과했다(오케스트레이터 확인; release job은 직접 대조).
- 기존 `offerFor` 규칙으로 Beta에서 `0.0.2 → 0.0.3-beta.1` 제공 및 Stable에서 거부를 실제 함수 호출로 확인했다. 이것은 실제 GitHub 전달 결과가 아니다.
- 공개 설치본 회귀 기준은 최신 `0.0.2` Stable로 갱신한다. GitHub API digest와 기존 Stable 기록의 설치 파일 SHA-256을 대조했다. 회귀는 공개 Stable 설치본에서 Settings의 Beta를 한 번 클릭하고 선택 반영을 기다린 뒤 로컬 feed의 후보로 업데이트하며 Beta 채널과 데이터를 보존한다. 릴리스 CI 전용이며 실제 GitHub 전달 검증은 아니다.
- `test:update`, `test:uninstall`, 공개 설치본 회귀 및 `test:update:github`는 로컬 미실행이다. 작업용 PC의 설치 상태를 바꾸지 않는다. CI local-feed·공개 설치본 결과와 실제 GitHub 업데이트를 구분한다.
- Store PowerShell 7 실환경, SmartScreen 및 signed delivery는 미검증이다.
