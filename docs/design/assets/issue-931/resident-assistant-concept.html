계통연계 기능 설계 검토

IEEE 1547 기준의 계통연계 요구사항을 정리하고, 차량 시스템과 OBCM 사이의 역할 및 동작 범위를 정의한다.

2. 계통 분리와 의도적 단독운전

계통 상태 판단, 계통 분리 보증, 운전 모드 전환은 인터페이스 책임을 명확히 나누어 검토한다.

2.2.1 V2H 전환 조건

차량 시스템은 계통과의 분리 상태를 보증한다. OBCM은 해당 보증 정보를 수신한 후 의도적 단독운전 명령을 수행한다.

검토 사항
계통 분리 상태의 유효성, 차량 명령의 선행조건, 복귀 시 동기화와 보호 시퀀스를 확인한다.

2.2.2 제어 역할 분담

시스템 분리 검출과 전력변환 제어는 별개의 책임으로 취급한다. 검증 근거와 파생 요구사항을 추적 가능하게 유지한다.
