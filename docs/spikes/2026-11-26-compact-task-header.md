# 2026-11-26 작업 탭 머리 영역 줄이기 세 시안 (#2016)

- Status: Historical
- Date: 2026-11-26 (브랜치 마지막 커밋일, KST)

## 목적

작업 탭 머리 영역(플러그인 화면·템플릿 갤러리가 함께 쓰는 머리)을 어떻게 줄이면 돌아가기·제목·상태·주요 동작을 잃지 않으면서 본문을 가장 위에서 시작하게 할 수 있는지 비교했다([#2016](https://github.com/litzio/litzio/issues/2016)).

## 무엇을 만들었나

개발 전용 스위치로 지금 모양과 세 시안을 바꿔 보이게 했다. 세 시안은 기존 토큰과 Button·Tooltip·Status만 쓴다.

- **A. 한 줄**: 돌아가기(아이콘만)·제목(패널 제목 크기)·대상 정보(파일 이름·쪽수, 작은 흐린 글씨)·설명 ⓘ tooltip·상태·동작을 한 줄에 둔다. 위아래 여백 12px.
- **B. 두 줄 축소**: 1줄은 A와 같고, 2줄에 설명을 작은 흐린 글씨 한 줄로 둔다. 위아래 여백 12px.
- **C. 최소형**: 제목은 탭 이름으로만 보이고, 40px 한 줄에 돌아가기·대상 정보·ⓘ·상태·동작만 둔다.

대상 정보 칸은 스파이크에서 새로 만든 칸으로, 플러그인 SDK 계약에는 없다.

## 결과·관찰

합성 플러그인 화면 두 개(대조형·목록형)와 템플릿 갤러리를 같은 조건에서 `pnpm browser:test`로 찍고 높이를 쟀다. 작업 탭 표면은 모든 경우 창 위 끝에서 73px에 시작한다. 머리는 구분선을 포함한 높이, 본문은 화면 틀 위 끝, 내용은 도구 줄 아래 대조 칸·목록 위 끝의 y좌표(px)다.

| 화면 | 지금 | A | B | C |
| --- | --- | --- | --- | --- |
| 대조형 1440×900 머리 / 본문 / 내용 | 150 / 247 / 295 | 57 / 154 / 202 | 71 / 168 / 216 | 40 / 137 / 185 |
| 목록형 1440×900 머리 / 본문 / 내용 | 114 / 211 / 259 | 57 / 154 / 202 | 67 / 164 / 212 | 40 / 137 / 185 |
| 템플릿 갤러리 1440×900 머리 / 본문 | 85 / 182 | 53 / 150 | 53 / 150 | 40 / 137 |
| 대조형 1920×1080 머리 / 본문 / 내용 | 150 / 247 / 295 | 57 / 154 / 202 | 71 / 168 / 216 | 40 / 137 / 185 |
| 대조형 640 한국어 다크 머리 / 본문 / 내용 | 198 / 295 / 343 | 101 / 198 / 246 | 119 / 216 / 264 | 84 / 181 / 229 |

- A는 대조 내용을 93px, B는 79px, C는 110px 위로 올린다.
- A는 머리에서 필요한 정보를 모두 한 줄에 남기지만 설명과 돌아가기 대상 이름은 마우스를 올려야 보인다.
- B는 설명이 늘 보이는 대신 A보다 14px 높고 설명이 한 줄로 잘린다.
- C는 가장 낮지만 머리만 보고는 어떤 화면인지 알 수 없고, 돌아가기·대상 정보가 없는 템플릿 갤러리는 왼쪽이 비어 보인다.
- 640에서는 세 시안 모두 기존 규칙대로 상태·동작이 둘째 줄로 내려간다. 아이콘만 남기거나 더 보기로 접는 처리는 만들지 않았다.

화면은 합성 자료로만 보았다. 문서 가져오기 플러그인의 실제 대조 화면, 키보드·화면 낭독기, 긴 제목, Desktop 앱은 확인하지 않았다. 머리 아래 본문까지의 24px 간격은 바꾸지 않았다.

캡처와 장단점은 [#2016 댓글](https://github.com/litzio/litzio/issues/2016#issuecomment-7182200040)에 있다.

## 현재 결정과 어긋나는 점

- [플러그인 화면 계약](../design/plugin-screens-v1.md)의 작업 탭 틀(템플릿 갤러리와 같은 24px 여백·제목 typography)과 달리, 세 시안은 머리 여백을 줄이고 제목을 패널 제목 크기로 낮춘다. C는 제목을 머리에서 뺀다.
- 같은 계약은 화면 설명을 머리에 표시한다. A·C는 설명을 tooltip으로 옮긴다.
- 돌아가기는 지금 이름이 보이는 버튼이다. 세 시안은 아이콘만 남긴다.
- 대상 정보 칸은 플러그인 SDK 공개 표면에 없는 새 칸이다.
