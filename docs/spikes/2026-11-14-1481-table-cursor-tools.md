# 표 커서 도구 배치 (#1481)

- Status: Historical
- 목적: 도구 예약 공간을 없애고 caret/focus 때 현재 행·열의 작은 테두리 도구를 띄우는 배치를 검토한다.
- 무엇을 만들었나: 합성 문서의 1440px 밝은/어두운 비교, 임시 CSS/DOM 시안, 공개 편집기 참고 조사.
- 결과·관찰: 보통 표의 시안은 커서 밖/안/메뉴 모두 135px로 동일했다. 현재 대비 76px 감소. 좁은 머리글 표본에서 Range 교차 0. 키보드·실제 엔진 선택은 시안의 수락 범위가 아니었다.
- 현재 결정과 어긋나는 점: 당시 Edit의 도구 공간 상시 예약·hover 표시와 다름. 현재 계약은 [표 상호작용](../design/table-interaction-v1.md)에 반영한다. 실제 행·열 선택은 이번 범위가 아니며 표시용 메뉴 대상 강조만 사용한다.
- 결론/후속: 채택(배치 방향). 소유자 승인 후 master 기준으로 다시 구현하며 스파이크 코드는 병합하지 않는다.
- 코드 위치: 브랜치 `spike/1481-table-cursor-tools`, 태그 `spike/2026-11-14-1481-table-cursor-tools`, 마지막 커밋 `586859c1de4e43e603d1c7557216dc5dd0d45a59`.
