# 2026-11-26 강조 세트 화면 배치 두 시안 (#2020)

- Status: Historical
- Date: 2026-11-26 (브랜치 마지막 커밋일, KST)

## 목적

승인된 강조 세트 기능(이름 있는 세트, 단어별 팔레트 색, 문서 자리에서 세트 고르기·문서별 기억·폴더 기본, 문서 안 단어 추가·색 바꾸기·빼기, 설정의 세트 정리)을 어떤 화면 배치로 보여 줄지 비교했다([#2020](https://github.com/litzio/litzio/issues/2020)). 기능 범위는 바꾸지 않았다.

## 무엇을 만들었나

메모리 안의 합성 세트로 동작하는 개발 전용 시안이다. 강조는 문서 내 찾기와 같은 ProseMirror 보기 장식이라 문서·dirty·Undo·저장을 바꾸지 않는다. 영어 단어는 단어 단위·대소문자 무시, 한국어·구절은 글자 그대로 맞춘다.

- **A**: 탭 줄의 형광펜 아이콘 버튼. 켜지면 세트 이름과 색 점을 보이고, 좁은 폭에서는 아이콘과 색 점만 남는다. 드롭다운은 세트 목록 / 끄기 / 이 폴더의 기본으로 / 세트 관리….
- **B**: 같은 메뉴를 ⋯ 파일 동작의 하위 메뉴로 두고, 켜져 있을 때만 탭 줄에 색 점 + 세트 이름 상태 표시.
- 두 시안 공통: 선택 도구 막대의 형광펜 버튼 → 8색 상자, 강조 단어 우클릭(색 바꾸기·빼기·세트 관리), 설정의 새 분류 `강조 세트`(Section·Row·Status로 세트·단어 칩·추가·이름 바꾸기·지우기).
- 팔레트 8색은 새 원시 색 값 없이 기존 강조색·상태색 토큰을 가리키는 조절 값(`--id-color-highlight-*`)이고 굵기는 650이다.

## 결과·관찰

합성 요구사항 문서에서 21곳이 강조됐고 `Mayday`·`Shallow` 속 낱말은 제외됐다. 같은 폴더의 다른 문서는 폴더 기본으로 켜졌다. 편집·읽기 보기와 플러그인 문서 보기에 보이는 것을 1440 밝음·다크, 1920×1080, 640 한국어 다크로 찍었다.

문서 종이 배경 기준 WCAG 대비비(밝음 `#ffffff`, 다크 `#1e2229`):

| 색 | 토큰 | 밝음 | 대비 | 다크 | 대비 |
| --- | --- | --- | --- | --- | --- |
| 파랑 | accent-blue | `#315fd4` | 5.65 | `#9abbff` | 8.30 |
| 초록 | accent-green | `#346d38` | 6.19 | `#9bce91` | 8.84 |
| 청록 | accent-teal | `#076f65` | 6.05 | `#6dd6c7` | 9.19 |
| 보라 | accent-violet | `#7041bd` | 6.60 | `#c4a8ff` | 7.90 |
| 자주 | accent-plum | `#8a3f85` | 6.71 | `#dda3d5` | 7.81 |
| 황토 | warning | `#875717` | 6.17 | `#efc079` | 9.49 |
| 빨강 | danger | `#a12b32` | 7.22 | `#ffa4aa` | 8.47 |
| 회색 | accent-graphite | `#52616b` | 6.40 | `#b5c6d1` | 9.09 |

- 모두 4.5 이상이지만 파랑은 링크·참조 색과 같고, 자주는 기본 강조색(선택 배경)과 같으며, 회색은 다크에서 본문 글자와 차이가 작다.
- A는 켜짐 여부와 세트가 탭 줄에 늘 보이고 한 번에 바꿀 수 있지만 탭 줄에 버튼이 하나 는다.
- B는 탭 줄이 덜 붐비지만 바꾸려면 두 단계를 거치고, 꺼져 있을 때는 기능이 탭 줄에서 보이지 않는다.
- 선택 도구 막대 상자와 우클릭 메뉴는 막대·문서 스크롤 영역에 잘려 문서 위 층으로 띄웠다.

합성 자료로만 보았다. 큰 문서에서의 장식 비용, 실제 저장과 문서·폴더별 기억, 명령 센터 항목, 비교 화면 캡처, 키보드·화면 낭독기, Desktop 앱은 확인하지 않았다. 우클릭 메뉴와 색 상자는 스파이크용 간이 구현이다.

캡처와 장단점은 [#2020 댓글](https://github.com/litzio/litzio/issues/2020#issuecomment-7183124708)에 있다.

## 현재 결정과 어긋나는 점

- [탭 줄 동작 계약](../design/editor-ux-shell-v1.md#title-strip-and-tab-row-actions-695)에 없는 버튼(A) 또는 상태 표시와 ⋯ 하위 메뉴(B)를 더한다.
- 선택 도구 막대에 버튼과 막대 밖 상자를 더하고, 강조된 단어 위 우클릭은 [본문 블록 메뉴](../design/editor-ux-shell-v1.md#body-block-context-menu-223) 대신 별도 메뉴를 연다.
- 설정 왼쪽 목록에 새 분류를 더한다.
- 이슈가 정한 대로 화면 언어 설정처럼 Core 연산·CLI 없는 로컬 보기 설정으로 두었다. 새 사용자 기능에 공용 작업과 CLI를 함께 두는 [ADR-0015](../adr/0015-shared-host-operations.md) 원칙과의 관계는 정식 구현에서 확인한다.

## 결론/후속

소유자가 2026-11-26에 시안 A를 골랐다. 팔레트의 링크 파랑·선택 자주와 다크 회색은 정식 구현에서 조정했고, 우클릭 메뉴와 색 상자는 공용 CommandMenu·Popover로 바꿨다. 정식 구현은 [#2029](https://github.com/litzio/litzio/pull/2029)와 그 뒤 PR이며 현재 계약은 [강조 세트](../design/editor-ux-shell-v1.md#highlight-sets-2020)다.
